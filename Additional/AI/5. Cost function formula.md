	Decides how much y changes when x changes.
	(If w is larger, small changes in x causes big changes in y)
- b(bias, also called t intercept)
	Control where the line crosses the y-axis.
	It shift the entire line up or down.

##### Cost Function
A cost function in machine learning is a mathematical function that measures how well(or badly) a model is performing.

It quantifies the **difference between the predicted output and the actual(true) output** for a given set of data. The main goal of training a model is to minimize the cost function so that predictions becomes as accurate as possible. 

For linear regression, the most common cost function is **Mean Squared Error(MSE)**,
$$
Cost=\frac{1}{n} \sum_{i=0}^{i=n}​{(y^{i}​−\widehat{y}^{i}​)}^2
$$
