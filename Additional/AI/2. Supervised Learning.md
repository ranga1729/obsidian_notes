Supervised learning refers to algorithms that learn input-output mappings. 
Key characteristic: we give the learning algorithm  examples to learn from.

Ex: 

| Input(X)           | Output(Y)           | Application         |
| ------------------ | ------------------- | ------------------- |
| email              | spam? (0/1)         | spam filtering      |
| audio              | text transcript     | speech recognition  |
| English            | Spanish             | machine translation |
| ad, user info      | click? (0/1)        | online advertising  |
| image, radar info  | position of the car | self driving car    |
| images of products | defect? (0/1)       | visual inpection    |
After the model has learned from these input-outputs, they can take a brand new input and try to produce a appropriate corresponding output. 

Supervised learning algorithms are mainly in two types,
1. Regression algorithms
2. Classification algorithms

*****
##### 1. Regression Algorithm
Purpose is to predict continuous values.
Output is a real-values number.

Ex: Predicting house prices
Learning data was marked on the chart. They represent a point in the chart(x,y).
X: House size
Y: Price
After learning from these data, it can predict the price of house if we give a new house size which isn't included in the training data set.
![[Pasted image 20250910181522.png]]

##### 2. Classification Algorithm
Purpose is to predict categorical labels.
Ex: 
	spam or not spam
	disease or not disease

Example scenario,
Breast cancer detection system : based on the patient data/lump size it will classify inputs into two categories "malignant"(cancer) or "benign"(not cancer)
![[Pasted image 20250910184404.png]]

**Main difference with regression algorithms,**
In classification tasks, we are trying to predict only a small number of possible outputs/categories/classes. 
In the above example image, we possible outputs are 0/1.
	0 : Malignant
	1: Benign
Regression algorithms try to predict any number among infinitely many number of possible number.
