All Nmap commands are in the syntax of,
```sh
nmap [Scan Type(s)] [Options] {target specification}
```

Common scan types are,

| Flag | Scan type        | Explanation                                                                                                                                                           |
| ---- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| -sS  | TCP SYN Scan     | Default scan type for root users. Often called a "half-open" scan because it initiates a TCP connection but never completes it. It's stealthy and fast.               |
| -sT  | TCP Connect Scan | Default scan type for non-root users. It completes the full TCP three-way handshake. Less stealthy than a SYN scan because the connection is fully established.       |
| -sU  | UDP Scan         | Scans for open UDP ports. Since UDP is connectionless, this scan type is much slower and more difficult. Often combined with a TCP scan like `nmap -sS -sU <target>`. |
| -sn  | Ping Scan        | A non-port scan. Only perform host discovery to see live hosts on a network without checking for open ports.                                                          |

Target specification can be in different types/formats,

| Value/Type     | Explanation                                                                | Example                |
| -------------- | -------------------------------------------------------------------------- | ---------------------- |
| IP Address     | Scans a single IP address                                                  | `nmap 192.168.1.1`     |
| Hostname       | Scans a specific domain name. Nmap will resolve the DNS first.             | `nmap www.google.com`  |
| Range of IPs   | Scans a range of IPs.                                                      | `nmap 192.168.1.1-20`  |
| CIDR notation  | Scans the entire subnet.                                                   | `nmap 192.168.1.0/24`  |
| List from file | The `-iL` flag tell Nmap to scan targets listed in the `targets.txt` file. | `nmap -iL targets.txt` |

#### Options
1. Port specifications
By default, Nmap scans the 1000 most common ports. You can customize by using,

| Command | Explanation                    | Value(s)                                                                                         |
| ------- | ------------------------------ | ------------------------------------------------------------------------------------------------ |
| -p      | Scan only the specified ports. | Single port: `-p 80`, Range: `-p 100`, List: `-p 80, 443, 8080`, All ports: `-p-` (from 1-65535) |
| -F      | Fast scan                      | Scans only the 100 most common ports. Faster that default option.                                |
2. Service version & OS detection
Help to learn more about the services running on open ports,

| Command | Feature                   | Explanation                                                                                                      |
| ------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| -sV     | Service/Version detection | Probes open ports to determine the services and version running on them. Useful for finding vulnerable software. |
| -O      | OS detection              | Identify target's OS. Require root privileges.                                                                   |
| -A      | Aggressive scan           | OS detection(`-O`), version detection(`-sV`), script scanning(`-sC`) and traceroute(`--traceroute`) all at once. |
3. Control the speed of your scan and how the results are saved,

| Command | Feature         | Value/Type                                    | Explanation                                                                                                                             | Example                 |
| ------- | --------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| -T      | Timing Template | 0-5                                           | Adjust the scan's speed. `-T0` is the slowest and `-T5` is the fastest while `-T4` is the most popular choice for a reliable fast scan. |                         |
| -oN     | Normal output   | `<filename>`                                  | Save the output in a normal, human readable format.                                                                                     | `-oN scan_results.txt`  |
| -oG     | Grepable Output | `<filename>`                                  | Saves the output in a format that's easy to manipulate with command-line tools like `grep` and `awk`                                    | `-oG scan_results.grep` |
| -oX     | XML output      | `<filename>`                                  | Saves the output in XML format, which is ideal for importing into other programs for analysis.                                          | `-oX scan_results.xml`  |
| -v      | Verbosity       | Use `-v` for some details and `-vv` for more. | Increases the amount of information Nmap displays while it is running. Useful for monitoring a scan's progress.                         |                         |

Ex:
A quick scan for live hosts on a network
```sh
nmap -sn 192.168.1.0/24
```
A fast, aggressive scan on a single target. 
```sh
sudo nmap -A -F 192.168.1.0
```
	-F : Fast scan
	-A : Agressive scan with OS detection, version detection, script scanning and traceroute
	Require sudo permission.
A detailed scan for web-related ports on a server and then saving the output.
```sh
sudo nmap -sS -sV -p 80,443,8080 scanme.nmap.org -oN nmap_report.txt
```
	-sS : Stealthy SYN scan
	-sV : Check for service versions on port 80,443,8080
	-oN : Save the result to a text file

------

1. Ping scan - Discover live hosts
This command sends host discovery probes(ARP/ICMP/TCP).
```sh
nmap -sn 192.168.56.0/24
```
2. TCP SYN scan(stealthy & fast
Sends `SYN` and waits for `SYN/ACK`(Open) or `RST`(Closed). Doesn't complete TCP handshake.
Used to look for open ports and their status. 
```sh
nmap -sS 192.168.56.101
```
3. TCP Connect scan(reliable)
```sh
nmap -sT 192.168.56.101
```
Uses OS `connect()` to finish handshake. Slower and noisier, but works without raw sockets.
Shows same port info as `-sS` but more likely to be logged.
4. Service & version detection
```sh
nmap -sV 192.168.56.101
```
Probes open ports with probes/signatures to identify service name & version. 
Used to look for service names(ssh, `http`, ftp) and version string. Crucial for vulnerability research.
5. OS detection
Sends varied probes and compares responses to fingerprint database.
```sh
nmap -O 192.168.56.101
```
6. Aggressive scan(all-in-one)
```sh
nmap -A 192.168.56.101
```
7. Scan specific port
```sh
nmap -p 22,80,443 <target_ip>
nmap -p- <target_ip> #all ports
```
8. Skip host discovery(treat host as up)
Useful when ICMP/ARP is blocked but service still respond.
```sh
nmap -Pn <target_ip>
```
9. UDP scan(slower, noisy)
Probes UDP ports(no handshake). slow and many false negatives. Combine with `-sV` for UDP service checks. 
Looks for open/closed/filtered port states.
Port states,
- Open : Service listening
- Closed: Reachable but no service
- Filtered: Packets blocked/dropped
9. Save output 
```sh
nmap -sV -oN result.txt -oX result.xml <target_ip>
```

#### Summary,
- Discover hosts: `nmap -sn <net>`
- Quick scan: `nmap <target>`
- SYN scan: `nmap -sS <target>`
- Connect scan: `nmap -sT <target>`
- Version detect: `nmap -sV <target>`
- OS detect: `nmap -O <target>`
- Aggressive: `nmap -A <target>`
- NSE scripts: `nmap --script <script|category> <target>`
- Save: `-oN`, `-oX`, `-oG`, `-oA`
