**Packet sniffing** means capturing network packets to analyze information like,
	IPs, MAC addresses, protocols and traffic pattern.
**Reconnaissance** is gathering information about a target network or system without direct exploitation. 

These are belongs to "information gathering" phase. 
#### Tools overview
1. **Airodump-ng**
	Captures raw 802.11 WiFi packets. 
	It's a part of the Aircrack-ng suite. 
	Good for wireless reconnaissance.
2. **Kismet**
	Passive wireless network detector and sniffer. 
	Logs SSIDs, channels, encryption types and clients. 
3. **Wireshark**
	General purpose packet analyzer with a GUI. 
	Good for deep protocol inspections. 
****
#### Workflow
1. Use airodump to identify target network+clients.
2. Use kismet to passively gather long-term data about devices and hidden networks.
3. Use Wireshark to analyze traffic for protocol weaknesses. (ex: un-encrypted HTTP, ARP, DNS leaks).
*****
#### Using `airmon-ng` & `airodump-ng`
1. Enable monitor mode
```sh
sudo airmon-ng start wlan0
```
2. Scan for Wi-Fi networks using `airodump-ng`
```sh
sudo airodump-ng wlan0mon
```
This will list, 
- BSSID(router MAC)
- Channel
- Encryption(WEP/WPA/WPA2)
- Connected clients
3. Capture packets from a specific network
```sh
sudo airodump-ng --bssid <target_bssid> --channel <channel> --write capture wlan0mon
```
`--write` : Set name of the file. This will create `capture.cap` for later analysis in Wireshark.

*****
#### Using kismet
1. Start kismet
```sh
sudo kismet
```
This will open a browser application on a specific port. 
It passively listen and logs,
- Hidden SSIDs
- Client-to-AP association
- Signal strength & channels
- Security settings(WEP/WPA2/WPA3)
Kismet is powerful because it's stealthy(doesn't actively probe)
****
#### Using Wireshark
1. Open Wireshark
```sh
sudo wireshark 
```
2. Capture packets, apply filters (e.g. `http`, `tcp.port == 80`, or `wlan.addr == <MAC>`).
3. It allows inspect,
	Handshakes (for WPA/WPA2 analysis)
	Protocol details (`ARP`, `DNS`, `HTTP`, etc.)
    Plain-text traffic on un-encrypted networks
