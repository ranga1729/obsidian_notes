Linux file system is different from windows. 
Linux doesn't have a physical drive(such as `c:` drive in windows) at the base of file system but uses a logical file system. 

Root of the file system is `/` known as 'root'(this is different from the root user).

Other most important directories,
1. `/root` : the home of the root user
2. `/etc` : Contains the Linux configuration files that control when and how programs startup
3. `/home` : The user's home
4. `/mnt` : where other file system are attached/mounted to the file systems
5. `/media` : Where CDs and USB devices are attached/mounted
6. `/bin` : Where application binaries resides(executables in windows)
7. `/lib` : Where libraries resided(shared programs that similar to DLLs in windows)
