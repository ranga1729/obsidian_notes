##### Pseudo Codes
Pseudo code is created when an algorithm is explain using simple English terms. 
Pseudo codes are independent of a computer language and can be converted into any programming language.

Explain Pseudo code basics. 
- BEGIN - To indicate a beginning
- END - To indicate an end
- INPUT, READ, GET - To indicate in input
- OUTPUT, DISPLAY, SHOW - To show an output
- PROCESS, CALCULATE - To indicate a process
- IF...THEN...ELSE...ENDIF - To indicate a selection
- FOR-DO, WHILE-ENDWHILE, REPEAT-UNTIL - Indicate a repetition
