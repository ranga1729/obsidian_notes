### Operating Systems
Network devices require an OS. 
![[Pasted image 20251216000753.png]]
- Shell
	User interacts with the shell to issue commands. 
	Types: GUI, CLI
- Kernel : Build the communication between software and hardware. Manages the hardware of a computer. 
- Hardware : Physical parts of a computer
#### GUI
- Allows the user to interact with a graphical environment. 
- Requires less knowledge of underlying command structure which control the system. 
- Ex: Windows, macOS, Linux KDE, Apple iOS, Android
- Disadvantages,
	1. Able to fail/crash.
	2. Resource intensive
#### Cisco Internetwork Operating System(IOS)
- Used on many Cisco routers and switches.
- It is possible to upgrade the IOS version/feature set for additional capabilities.
- Types of Cisco OSs : 
	1. Cisco IOS : For traditional routers/switches
	2. IOS XE(Linux-based)
	3. IOS XR : Carrier-grade. For service providers
	4. NX-OS : Nexus for data centers
### Access Method
- All switches comes with default settings. Regardless, all switches should be configured and secured.
Methods,
1. Console
	A physical management port provides out-of-band(dedicated management channel used for device maintenance only) access to a Cisco device. A terminal application can be used to execute commands.
	![[Pasted image 20251216003206.png]]
	![[Pasted image 20251216003045.png]]
2. Secure Shell(SSH)
	In-band and recommended method for remotely establish a secure CLI connection over a network. Require an active networking service on the device. Most versions of Cisco IOS include an SSH server and SSH client that can be used to establish SSH sessions.
3. Telnet
	Insecure and in-band method of remotely establish a CLI session over a network. Unlike SSH, telnet doesn't provide a encrypted connection(User auth, passwords and commands are sent in plaintext). Cisco IOS includes Telnet server and Telnet client.

Some devices(like routers) may support AUX port that used to establish a CLI session over a telephone connection using a modem. AUX port is out-of-band and doesn't require service to be configured to use. 
### Terminal Emulation Programs
Used to connect to a networking device either by a serial connection or console port or SSH/Telnet connection. 
Ex: PuTTY, Tera Term, SecureCRT
