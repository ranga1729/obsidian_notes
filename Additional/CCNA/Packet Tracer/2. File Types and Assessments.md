Four file types that Packet Tracer can create,
1. `.pka`
PKA = Packet Tracer Activity file
A packet tracer has an instruction window which provides the procedures required to complete the activity, assignment or assessments, and to display completion percentage.
These files has two networks,
- Initial Network : 
	Opens when the activity is launched. 
- Answer Network 
	Runs in the background.
	Used to provide scoring and feedback to learners as they complete the activity. 
	Learners do not have access to this network. 

2. `.pkt`
Created when a simulated network is built in packet tracer and saved. 
Can also have graphic background images embedded inside. 
Have no instruction window or activity scoring. 

3. `.pksz` 
Specific to Packet Tracer Tutored Activities(PTTA).
These files bundles a `.pka` file, media assets and a scripting file for the hinting system. 

4. `pkz` (Deprecated)
Previously used to embed images and other files in a Packet Tracer file.
But images are now embedded directly within a `.pkt` or `.pka` file.

#### Cisco Packet Tracer Assessments
Two types,
1. Packet Tracer Media Objects(PTMO)
	Can be either a `.pkt` or a `.pka` file. 
	Can include quiz, module exams or other types of graded assessments. 
	Can launch the `.pkt` or `.pka` file directly from inside the assessment. 
	It allows you to configure or investigate the topology, and then answer a multiple choice assessments questions.
2. Packet Tracer Skills Assessments(PTSA)
	Summative skills assessments which allows you to demonstrate your skill by implementing the technologies. 
	Standalone assessments with their own grading engine.
