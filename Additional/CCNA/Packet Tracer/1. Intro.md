Packet tracer provides a variety of tabs for device configuration including the following,
1. Physical tab
2. Config tab
3. CLI tab
4. Desktop tab
5. Services tab
#### 1. Physical
![[Pasted image 20251202160611.png]]
Provides an interface for interacting with the device including,
- Powering it on/off
- Installing different modules
#### 2. Config
For intermediate devices(routers, switches) there are two ways to access device configurations. 
1. Config tab(GUI)
2. CLI
![[Pasted image 20251202160955.png]]
- GUI provides a way to change device configs visually.
- Or you can use the CLI to to change configs. 
When changes happened through the GUI, the CLI tab will show the equivalent commands run in there. 
#### 3. CLI tab
Provides a CLI interface of a Cisco device. It requires knowledge of device configuration with IOS. 
 Any commands that were entered from the Config tab are also shown in the CLI tab.

#### Console cables
![[Pasted image 20251203002342.png]]
AKA "rollover cable" or "management cable". 
Used for out-of-band management of networking devices such as routers, switches and firewalls. (out-of-band = when the device is down)

Main purpose : Establish a direct, serial connection between a computer and the device's console port to access the CLI. 
Functions: 
	Perform initial configuration
	Troubleshooting
	System recovery
Connector :
	Networking device side usually use a RJ45 connector and the computer end often uses a USB connector(or a DB9 serial port in older computers).

Console cable vs. Ethernet cable

| Feature             | Console                            | Ethernet                             |
| ------------------- | ---------------------------------- | ------------------------------------ |
| Primary purpose     | Device management/configuration    | Data transmission                    |
| Types of connection | Direct Serial(Terminal) Connection | Network connection                   |
| Data transfer rate  | Low-speed(ex: 9600 bps)            | High-speed(Up to 1 Gbps)             |
| Wiring              | Rollover pinout(rear side)         | Straight through or crossover pinout |
| Protocol            | Serial communication(ex: RS-232)   | Uses Ethernet(ex: IEEE 802.3)        |

In modern networking, you have two primary ways to establish a console access(direct terminal connection),
1. Traditional Console Cable(RJ45 to DB9/USB adapter) : often requiring a separate USB-to-Serial adapter for modern laptops.
2. USB Console Cable : Computer USB Type-A to a Mini-USB/Micro-USB console port found on newer networking devices.
