Protocol suite is an inter-related protocols related to perform a communication function. 
In a protocol suite, protocol are viewed in terms of layers,
- Higher layers
- Lower layers - moving data and service to upper layers

During the evolutions, there were several protocol suites competing each other.
![[Pasted image 20260524142309.png]]
- Internet Protocol Suite(TCP/IP): The most common suite maintained by the Internet Engineering Task Force(IETF)
- Open Systems Interconnection(OSI): Developed by ISO and International Telecommunication Union(ITU)
- Apple Talk: Proprietary suite release by Apple Inc.
- Novell NetWare: Proprietary suite by Novell Inc. 
### TCP/IP Protocol Suite
Protocols in this suite operate in the applications, transport and internet layers. 
![[Pasted image 20260524142959.png]]
The most common network access layers are LAN, Ethernet and WLAN. (Example only shows Ethernet.)

Today, the TCP/IP protocol suite includes many protocols and continues to evolve to support new services. 
![[Pasted image 20260524143323.png]]

Ex: sending data from a server to a client pc. 
![[Pasted image 20260524144316.png]]

TCP/IP stack doesn't refers to the OSI model. OSI is a 7-layer conceptual framework by the ISO standards. serves as a universal guide for network design. 
TCP/IP is a practical, real-world, 4-layer framework.
