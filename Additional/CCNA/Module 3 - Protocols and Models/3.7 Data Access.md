### Addresses
Two OSI layers uses addressing,
1. Network Layer - Responsible for delivering the IP packet from the original source to the final destination.
2. Data link layer - Responsible for delivering the data link frame from one interface card to another interface card.

### Layer 3 Logical Address
![[Pasted image 20260524174545.png]]
Layer 3 = Network Layer = IP addressing
These logical address used to deliver IP packet from the original source to the final destination. 
![[Pasted image 20260524174520.png]]

An IP address contains two part,
1. Network Portion(IPv4) or Prefix(IPv6)
	The left-most part. 
	Indicate the network group which the IP address is a member.
	Each LAN or WAN will have the same network portion.
2. Host Portion(IPv4) or Interface ID(IPv6)
	The remaining part of the address. 
	Identifies a specific device within the group.
	Unique for each device on the network.

The subnet mask(IPv4) or prefix-length(IPv4) is used to identify the network portion of an IP address from the host portion. 
### Devices on the Same Network
When devices on the same network share data to each other, source and destination will have the same value in network portion of the address.
Ex: 
![[Pasted image 20260524185728.png]]
PC1 - `192.168.1.110`
PC2 - `192.168.1.9`

When the sender and receiver of the IP packet are on the same network, the data link frame is sent directly to the receiving device. 
On an Ethernet network, the data link addresses are known as Ethernet Media Access Control(MAC) addresses. 

MAC addresses are physically embedded into the Ethernet NIC and are local addressing.
- The Source MAC address will be that of the originator on the link.
- The Destination MAC address will always be on the same link as the source, even if the ultimate destination is remote.
### Devices on different IP Networks
When the final destination is remote, Layer 3 will provide Layer 2 with the local default gateway IP address, also known as the router address. 
![[Pasted image 20260524185823.png]]
- The default gateway is the router.(`192.168.12.1`)
- All devices on the LAN must be aware of this default gateway.

Source IP - `192.168.1.110` (Source device)
Source MAC - `AA-AA-AA-AA-AA-AA` (Source device)

Destination IP - `172.16.1.99` (Destination device, out of the source network)
Destination MAC - `11-11-11-11-11-11` (Default Gate of the source device. Same network)

This packet will be send to the Router(Gateway) first. 
Once layer 2 on PC1 forward the packet there, the router will start routing process of getting the information to actual destination. 
While the L2 local addressing(MAC) will change from link to link or hop to hop, the L3 addressing(IP) remains the same.

The data link addressing are always local to the network.
