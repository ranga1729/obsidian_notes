Protocols are a set of rules that devices in a network adhere to communicate with each other. 

Types of protocols,
1. Network communication protocols - enable two or more devices to communicate over one or more networks. 
	ex: IP, TCP, HTTP
2. Network security protocols - Secure data by providing authentication, data integrity and data encryption. 
	ex: SSH, SSL, TLS
3. Routing protocols - Enable routers to exchange route information, compare path information, select the best path to the destination network. 
	ex: OSPF, BGP
4. Service discovery protocol - Automatic detection of devices or services. 
	ex: DHCP, DNS

##### Functions of a Protocol,
1. Addressing - Identifies the sender and the intended receiver of the message.
2. Reliability - Provide guaranteed delivery mechanisms in case messages are lost or corrupted in transit. 
3. Flow control - Ensures that data flows at an efficient rate between two devices.
4. Sequencing - Uniquely labels each transmitted segment of data. Receiver uses this sequencing to re-assemble the information correctly. 
5. Error detection - Used to determine is data became corrupted. 
6. Application interface - Contains information used for process-to-process communications between network applications.

- HTTP(Hyper Text Transfer Protocol) - Governs the way a web server and a web client interacts, defines the content and formatting of the request and response. 
- TCP(Transmission Control Protocol) - Responsible for guaranteeing the reliable delivery of the information and managing flow control between the end devices. 
- IP(Internet Protocol) - Responsible for delivering the message from the sender to the receiver. Used by routers to forward the message across multiple networks. 
- Ethernet - Responsible for the delivery of the message from once NIC to another NIC on the same LAN.
