Network protocols define a common set of rules.
Types of protocols,

| Type                  | Description                                                        |
| --------------------- | ------------------------------------------------------------------ |
| Network Communication | Enable devices to communicate with each other. (ex: IP, TCP, HTTP) |
| Network Security      | Secure data. (ex: SSH, SSL, TLS)                                   |
| Routing               | Enable routers to exchange route information. (ex: OSPF, BGP)      |
| Service Discovery     | Automatic detection of devices or services. (ex: DHCP, DNS)        |
Network communication protocols are responsible for some functions,
1. Addressing - Identifies the sender and the receiver. (ex: IPv4, IPv6)
2. Reliability - Provides guaranteed delivery mechanisms. (ex: TCP provides guaranteed delivery)
3. Flow control - Ensures data flows at efficient rate. (ex: TCP)
4. Sequencing - Uniquely labels each transmitted segment of data. 
5. Error detection - Determine if data became corrupted during transmission. (ex: IPv4, IPv6, TCP)
6. Application Interface - Contains info used for process-to-process communication.(ex: HTTP, HTTPS)

When a message sent over a network, it requires multiple protocols, each one with its own function and format.
