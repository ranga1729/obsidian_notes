Common external threats,
- Viruses, worms & Trojan horses : Run malicious code on a device
- Spyware & adware : Secretly collect information about the user. 
- Zero-day attacks
- Threat actor attacks : A malicious person attacks user devices/networks
- DoS : Slow down or crashes applications
- Data interception and theft : Captures private information 
- Identity theft : Steals login credentials of a user

- Studies shows that most common data breaches happen because of internal users of the network. 
	Ex: via a lost /stolen device, a misuse by employees, malicious employees
#### Solutions
- Implement multi layered security solutions. (If one layer fails, the other level will detect the threat).
- Common security measures for home/small offices,
	1. Antivirus and antispyware
	2. firewall filtering
- For large corporations,
	1. Dedicated firewall system 
		Provide more advanced firewall capabilities that can filter large amount of traffic
	2. Access control list(ACL) 
		Further filter access and traffic forwarding based on IP addresses and applications.
	3. Intrusion Prevention systems(IPS) 
		Identify fast-spreading threats(ex: zero-day attacks)
	4. Virtual Private Networks(VPN) 
		Provide secure access into an organization for remote workers.
