Key ideas of Dart,

#### Variables
- Every variable must have a type. 
- Variable are created using `var` keyword.
- `final` : used to create run time constants
- `const` : used to create compile time constants
Ex:
```dart
void main() {
	var name = "Ranga";
	print(name); //Ranga
	name = "Pasan";
	print(name); //Pasan
	
	final age;
	age = 25;
	
	const byear = 200;
	
	print("my name is $name and my age is $age I was born in $byear")
}
```

#### Variable & Types
- Explicit typing
```dart
int age = 22;
double price = 99.99;
string name = "John";
bool isLoggedIn = true;
```

- Type inference (let the compiler determine the type based on the initial value)
```dart
var city = "London"; //string
var count = 10;
```
You can not change type afterwards.
#### `final` vs `const`
1. `final`
	Used to set constant.
	Decided at runtime. 
```dart
final currentTime = DateTime.now();
```
2. `const
	Value set at compiler time.
	Immutable forever.
```dart
const pi = 3.14159
```

**Use `const` whenever possible.**
#### Null Safety
By default variable can not be null unless explicitly mentioned. 
```dart
int x = 10;
x = null; //error

int? y;
y = null; //allowed

int? a = 5;
print(a!); //null check operator(similar to TS)

string? name;
print(name ?? "Guest"); //if name is null "Guest" will be printed
name?.length; //safely access a nullable variable
```

#### Constructors & named constructors
Dart doesn't allow constructor overloading. Named constructors address this limitation by allowing a class to have custom constructors that gives a class multiple ways to create an object with unique, descriptive names. 
```dart
Class Profile {
	String name;
	int age;
	
	Profile(this.name, this.age);
	
	Profile.onlyName(this.name) {
		age = 0;
	}
	
	Profile.onlyAge(this.age) {
		name = "unknown";
	}
}

//usage
var profile_1 = Profile("Jack", 22);
var profile_2 = Profile.onlyName("Harry");
var profile_3 = Profile.onlyAge(18);
```
