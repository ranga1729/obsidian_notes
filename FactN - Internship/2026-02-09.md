#### Grafana
An open-source platform for data visualization, monitoring and analysis. 
Used to create interactive, real-time dashboards by getting info from Prometheus, MySQL, AWS, ...
Specialized in time-series data, enabling DevOps teams to visualize metrics, logs and application performance, infrastructure health.

#### Miro Board

#### Kafka(Apache)
A distributed event streaming platform used for high-performance data pipelines, streaming analytics, and data integration. Runs as a cluster of servers(brokers) that can span multiple data centers.
Uses a pub/sub model & parallel processing to maintain high throughput and scalability. 

Kafka Queue - Refers to using Kafka's topics to act as a message queue for distributing tasks to multiple consumers.

#### SRS
Software Requirement Specification is a structured document acting as a blueprint for software development. Focus on both functional and non-functional requirements.

Key aspects,
- Define project goals and boundaries.
- Describe specific behaviors, features and user interactions. 
- Outline system qualities like security, usability, maintainability and performance. 
- Mention hardware, software limitations.
