Main principles,
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
#### 1. Encapsulation
Process of hiding data and only allowing access through public methods. 
Ensures that the internal state of an object is protected from unintended modification.

Ex:
```C#
class BankAccount
{
	private double balance; //private field
	public void Deposit(double amount)
	{
		if(amount > 0)
		{
			balance += amount;
		}
	}
	public double GetBlance()
	{
		return balance;
	}
}
```
- `balance` is a private field.
- `Deposit` method controls access, ensuring that only valid deposits are made. 
#### 2. Inheritance
Allows one class to inherit properties and methods from another class. 
Ex:
```C#
class Animal 
{
	public void Eat()
	{
		Console.WriteLine("Eating");
	}
}

class Dog : Animal
{
	public void Bark()
	{
		Console.WriteLine("Barking")
	}
}

Dog myDog = new Dog();
myDog.Eat();
myDog.Bark();
```
- `Dog` class inherits from the Animal class.
- `Eat()` method is defined in Animal and reused in `Dog`.
#### 3. Polymorphism
Allows a single interface (method) to behave differently in different context.
##### 1. Method Overriding(Runtime Polymorphism)
Allows a child class to provide a specific implementation of a method defined in a parent class. 
Ex:
```C#
class Animal
{
	public virtual void MakeSound()
	{
		Console.WriteLine("Animal sound");
	}
}
class Dog : Animal
{
	public override void MakeSound()
	{
		Console.WriteLine("Dog barks.")
	}
}
class Cat : Animal
{
	public override void MakeSound()
	{
		Console.WriteLine("Dog meows.")
	}
}

Animal myAnimal;
myAnimal = new Dog();
myAnimal.MakeSound(); //barks
myAnimal = new Cat(); //meows
```
##### 2. Method Overloading(Compile-time Polymorphism)
Allows multiple methods with the same name but different parameters. 
```C#
class MathOperations 
{ 
	public int Add(int a, int b) 
	{ 
		return a + b; 
	} 
	public double Add(double a, double b) 
	{ 
		return a + b; 
	} 
}
MathOperations math = new MathOperations(); Console.WriteLine(math.Add(5, 10)); // Calls Add(int, int) 
Console.WriteLine(math.Add(5.5, 2.5)); // Calls Add(double, double)
```
- The correct method is **selected at compile time** based on argument types.
#### 4. Abstraction
Hides complex implementation and expose only the necessary functionality.
##### 1. Using Abstract Classes
```C#
abstract class Shape
{
	public abstract double GetArea(); // Abstract method
}
class Circle : Shape
{
	private double radius;
	public Circle(double r)
	{
		radius = r;
	}
	public override double GetArea() 
	{ 
		return Math.PI * radius * radius; 
	}
}
Shape myCircle = new Circle(5);
Console.WriteLine(myCircle.GetArea()); // Output: 78.54
```
##### 2. Using Interfaces
```C#
interface IAnimal
{
	void speak();
}
class Dog : IAnimal
{
	public void Speak()
	{
		Console.WriteLine("Dog barks.");
	}
}
IAnimal myDog = new Dog(); 
myDog.Speak(); // Output: Dog barks.
```
