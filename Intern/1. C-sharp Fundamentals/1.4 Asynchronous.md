Allows non-blocking programming. 
Useful for I/O-bound operations.
Ex: 
- Database calls
- API calls
- File operations
- Any operation that takes rime and could block the main thread

Key concepts, 
1. The **async** and **await** keywords
- **async** : marks methods as asynchronous
- **await** : suspends execution of an asynchronous method until the awaited task completed without blocking the thread. 

2. **Task** and **Task`<`T`>`**
- **Task** : Represent an asynchronous operation that doesn't return a result.
- **Task`<T>`** : Represent an asynchronous operation that returns a result of type `T`.

Ex: Asynchronous method
```C#
using System;
using System.Threading.Tasks;

Class Program
{
	static async Task Main()
	{
		Console.WriteLine("Fetching data...");
		string result = await GetDataAsync();
		Console.WriteLine($"Data received: {result}");
	}
	static async Task<string> GetDataAsync() 
	{ 
		await Task.Delay(3000); // Simulates a delay (e.g., network request) 
		return "Hello, Async World!"; }
}
```
- The `Main` method calls `await GetDataAsync()`, ensuring it waits for the result before proceeding.

3. Try-Catch block
Use exception handling in async methods.
Ex: 
```C#
static async Task<string> GetDataAsync()
{
    try
    {
        await Task.Delay(3000);
        throw new Exception("Something went wrong!");
    }
    catch (Exception ex)
    {
        return $"Error: {ex.Message}";
    }
}
```

4. Parallel execution of Asynchronous tasks
We can run multiple tasks in parallel using `Tasks.WhenAll`
Ex:
```C#
static async Task Main()
{
    Task<string> task1 = GetDataAsync();
    Task<string> task2 = GetDataAsync();

    string[] results = await Task.WhenAll(task1, task2);
    Console.WriteLine($"Results: {string.Join(", ", results)}");
}
```
- `Task.WhenAll` method runs multiple asynchronous tasks in parallel and waits for all of them to complete before proceeding. 


> [!NOTE] Avoid `aync void` (use `async Task`)
> `void` methods cannot be waited and error handling becomes difficult. 
> Instead use `Task` or `Task<t>`.
> ```C#
> static async Task SomeMethodAsync()
> {
> 	await Task.Delay(1000);
> }
> ```
