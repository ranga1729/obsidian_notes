- LINQ = Language Integrated Query
- Allows querying collections, databases, XML and more. 
- Syntaxes,
	1. Query syntax(SQL-like)
	2. Method Syntax(Lambda expressions)

#### LINQ with collections (List, Array)
Filtering a list.
Ex: Filter number greater than 20
```C#
List<int> numbers = new List<int> {10, 20, 30, 40, 500};

//Query syntax
var result1 = 
from num from numbers
where num > 20
select num;

//Method syntax
var result2 = numbers.Where(num => num > 20);
```

#### LINQ Operations
1. **Select**
- Used to transform data.
Ex: Convert names into uppercase
```C#
List<string> names = new List<string> {"Alice", "Bob", "Charlie"};
var result = names.Select(name => name.ToUpper());
```

2. **OrderBy & OrderByDescending**
```C#
List<int> nums = new List<int> {30, 10, 50, 20};

//ascending order
var ascOrder = nums.OrderBy(n => n);

//descending order
var descOrder = nums.OrderByDescending(n => n);
```

4. **Join** (joining two lists)
```C#
var students = new List<int> {1, 2, 3};
var names = new List<(int Id, string Name)> 
{ (a, "Alice"), (2, "Bob"), (3, "Charlie") };

var result = 
from student in students
join name in names on student equals name.Id
select name.Name;

Console.WriteLine(string.Join(",", result)); //Output: Alice, Bob, Charlie
```
#### LINQ with Databases (Entity Framework)
Ex: fetch students from databases
```C#
var students = dbContext.Students
.Where(s => s.Age > 18)
.OrderBy(s => s.Name)
.ToList();
```
#### LINQ with XML
Ex: Read XML Data
```C#
XDocument xml = XDocument.Load(students.xml);
var studentName = 
from student in xml.Descendants("Students")
select student.Element("Name").Value;
```
