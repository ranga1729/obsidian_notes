Two main categories,
1. Value Types(stored in stack)
2. Reference Types(Stored in Heaps)

##### 1. Value Types
- int
- double
- float
	`float temp = 36.5f;`
- char
- bool
- byte
- short
- long
	`long population = 7800000000L;`

##### 2. Reference Types
- string
- object
- dynamic
	dynamic x = "hello";
	x = 5;

##### 3. Nullable Types 
Allows value types to hold `null`.
Ex: 
```C#
int? age = null;
double? price = 10.99;
```
##### 4. Collection
Used to store multiple values efficiently. 

4.1 `List<T>`
- Resizable
- Ordered
- Dynamic Array
- Store elements of the same type.
```C#
List<int> numbers = new List<int> {1, 2, 3, 4, 5};
numbers.Add(6);
numbers.Remove(3);

foreach(int num in numbers)
{
	Console.WriteLine(num);
}
```

4.2 `Dictionary<TKey, TValue>` (Key-Value pair)
Stores key-value pairs, where each key is unique.
- Fast lookup
- Keys must be unique
- Value can be duplicate
EX:
```C#
Dictionary<int, string> students = new Dictionary<int, string>
{
	{1, "Alice"},
	{2, "Bob"},
	{3, "Charlie"}
};
Console.WriteLine(student[2]); //Bob
```

4.3 `Queue<T>` (FIFO - First In, First Out)
```C#
Queue<string> tasks = new Queue<string>();
tasks.Enqueue("Task 1");
tasks.Enqueue("Task 2");
tasks.Enqueue("Task 3");
console.WriteLine(tasks.Dequeue()); //Task 1
```

4.4 `Stack<T>` (LIFO - Last In, First Out)
```C#
Stack<int> stack = new Stack<int>();
stack.Push(10);
stack.Push(20);
stack.Push(30);
stack.Push(40);
Console.WriteLine(stack.Pop()); //30
```
