Introduced in React 16.8.
React hooks are functions that allows to use state and other react features in functional components.

Common examples,
#### 1. `useState`
Used to manage state within a functional component.
Returns an array with the current state value and a function to update it.
```js
function Counter() {
	const [count, setCount] = useState(0);
	return (
		<div>
			<p>You clicked {count} times</p>
			<button onClick={() => setCount(count + 1)}>
			Click me</button>
		</div>
  );
}
```
#### 2. `useEffect`
Handles side effects in functional components. 
Runs after a render.
Ex: data fetching
