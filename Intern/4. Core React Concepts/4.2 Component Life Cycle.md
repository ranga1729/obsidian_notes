Three phases,
1. Mounting phase
2. Updating phase
3. Unmounting phase

#### 1. Mounting phase
The component is being created and inserted into the DOM.

Primary life cycle methods:
1. `constructor(props)`
	- Invoked before the component is mounted. 
	- Used for initializing state and binding event handlers. 
2. `static getDerivedStatefromProps(props, state)`
	- Called right before rendering, both during the initial mount and subsequent updates. 
	- Allows the state to be updated based on props.
3. `render()`
	- The only required method in a class component.
	- Examines `this.props` and `this.state` and return react elements, arrays, fragments, strings, ...etc.
4. `componentDidMount()`
	- Executes after the component is mounted.
	- Used for side effects. 
#### 2. Updating phase
Happens when a component's state or props change, leading to a re-render.

Primary life cycle methods,
1. `static getDerivedStatefromProps(props, state)
	- Allows the state to be updated based on props.
2. `shouldComponentUpdate(nextProps, nextState)`
	- Determine whether the component should re-render in response to state or prop change.
	- Used for performance optimization by preventing unnecessary renders.
3. `render()`
	- Re-examine `this.props` and `this.state` and returns the updated react element.
4. `getSnapshotBeforeUpdate(prevProps, prevState)`
	- Called right before DOM is updated. 
	- Allows capturing information(ex: scroll position) before changes are made. 
	- The value returned is passed to ``componenetDidUpdate()` method.
5. `componentDidUpdate(prevProps, prevState, snapshot)`
	- Executed after the component's updates are flushed to the DOM.
	- Suitable for performing operations that depends on the DOM.
		Ex: manipulating the DOM
#### 3. Unmounting phase
Occurs when a component is being removed from the DOM.

Life cycle methods,
1. `componentWillUnmount()`
	- Invoke immediately before a component is unmounted and destroyed. 
	- Used for cleanup tasks.
		Ex: Invalidating timers, cancelling network requests, cleaning up subscriptions
