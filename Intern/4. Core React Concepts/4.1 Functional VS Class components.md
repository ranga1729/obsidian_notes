Components are the building block of a UI.
Types of components,
1. Functional components
2. Class components
#### Class Components
Class components are ES6 classes that extend `React.Component`.
Include a `render()` method to return JSX.
Ex:
```js
import React, {Component} from 'react';

class Greeting extends Components {
	render() {
		return <h1>Hello, {this.props.name}</h1>;
	}
}
export defualt Greeting;
```
- Uses `this.state` to manage local state.
- Slower and complex compared to a functional component. 

**Rules**: 
1. Define class components by extending `React.Component`
2. Initialize state within the constructor or as a class property. 
```js
class MyComponent extends React.Component {
	constructor(props) {
		super(props);
		this.state = {count:0};
	}
}
```
3. Bind event handlers to the class instance, typically in the constructor, to ensure the correct `this` context.
```js
class MyComponent extends React.Component {
	constructor(props) {
		super(props);
		this.handleClick = this.handleClick.bind(this);
	}
	handleClick() {
		//definition
	}
}
```
4. Utilize lifecycle methods to manage side effects and components behavior during different stages of its lifecycle.
```js
class MyComponent extends React.Component {
	componentDidMount() {
		//perform side effect
	}
	componentWillUnmount() {
		//cleanup
	}
}
```
5. Treat props immutable and avoid direct modifications.
6. Hooks can not be used in class components.

----
#### Functional Components
Simple JavaScript functions that accept props and return JSX(React element).
Ex:
```js
import React from "react";
const Greeting = ({name}) => {
	return <h1>Hello, {name}</h1>
}
export default Greeting;
```
- Simpler and easier to read.
- Uses react hooks to manage state and lifecycle events. 
- Does not require `this` keyword. 

**Rules** : 
1. Use `PascalCase` for component naming. 
	`function Greeting() {...}`
2. Call hooks at the top of the component or custom hooks.
3. Avoid calling hooks,
	Inside loops,
	Conditions,
	Nested functions. This is to make sure consistent hook invocation order across renders. 
```js
function MyComponent() {
	const [count, setCount] = useState(0); //correct
	
	if(condition) {
		useEffect(() => {..}); //incorrect
	}
}
```
4. Do not modify props directly int the component. Treat them as immutable.
```js
function MyComponent({items}) {
	item = 5; //incorrect - avoid direct prop modification
	items.push(newItem); //incorrect

	const x = item; //ok
	x = x + 6;
}
```
5. Ensure that side effects are managed outside of the rendering process.

----
##### Differences

| Feature           | Functional             | Class                                    |
| ----------------- | ---------------------- | ---------------------------------------- |
| State management  | Uses hooks(`useState`) | Uses `this.state`                        |
| Lifecycle Methods | Uses hook(`useEffect`) | Uses `componentDidMount()`               |
| `this` keyword    | Not required           | Required(ex: `this.state`, `this.props`) |
| Performance       | Faster                 | Slower                                   |
| Readability       | Easy                   | Complex                                  |
