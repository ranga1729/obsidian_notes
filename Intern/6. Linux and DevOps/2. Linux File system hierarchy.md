1. `/` - Root directory
Everything in the system is located under the root directory including other mounted drives. 

2. `/bin` - Binary executables
Contains essential command-line programs used by all users.

3. `/sbin` - System binaries
Contains essential system administration commands (mostly for root users).
Ex: reboot, shutdown

4. `/boot` - Boot loader file
Contains the files required for booting the system. 
Ex: 
	`vmlinuz` : the Linux kernel
	`grub` : the bootloader directory

5. `/dev` - Device files
Contains special files representing system devices (hard drives, USBs, etc.).
Ex: 
	`/dev/sda` : first hard disk
	`/dev/tty` : terminal
	`/dev/null` : discard data

6. `/etc` - Configuration files
Stores system-wide configuration files.
Ex:
	`/etc/passwd` : User account info
	`/etc/fstab` : Mounted file systems
	`/etc/hostname` : System hostname

7. `/home` - User home directories
Contains personal directories for users.
Ex:
	`/home/user1/`
	`/home/user2/`

8. `/lib` - Libraries for binaries
Stores essential system needed by `/bin` and `/sbin` program.
Ex:
	`/lib/libc.so.6` : Standard C library

9. `/media` & `/mnt` - Mount points
`/media` : Auto-mounts external storage. (USB, CD-ROM)
`/mnt` : Used for manually mounting temporary file systems.

10. `/opt` - Optional software
Contain additional software installed by the user. 
Ex: 
	`/opt/google-chrome`

11. `/proc` - Kernel and Process info
Virtual filesystem providing real-time system info.
Ex:
	`/proc/cpuinfo` : CPU details
	`/proc/meminfo` : Memory usage
	`/proc/uptime` : System uptime

12. `/root` - Root user's home
Home directory for the root(superuser)
Unlike `home`, this is directly user `/`.

13. `/run` - Runtime data
Stores temporary system info since the last boot.
Ex:
	`/run/utmp` : Logged in users info

14. `/srv` - Service data
Stores data for system services.
Ex:
	`/srv/www/` : Website data

15. `/tmp` : Temporary files
Stores temporary files, usually deleted after reboot.

16. `/usr` - User binaries and programs
Stores software and libraries not essential for booting. 
Ex:
	`/usr/bin` : User installed programs
	`/usr/sbin` : System administration tools
	`/usr/local` : Locally compiled programs

17. `/var` - Variable Data
Storage logs, caches and other variable files.
Ex: 
	`/var/log/syslog` : System logs
	`/var/spool/mail` : Email queue
