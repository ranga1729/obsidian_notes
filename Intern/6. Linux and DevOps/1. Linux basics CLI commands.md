### File and directory management
1. `ls` - list files in a directory
```bash
ls -l #detailed list
ls -a #showhidden files
```
2. `cd` - change directory
```bash
cd /path/to/directory
cd .. #move up one level
```
3. `pwd` - print working directory
4. `mkdir` - make a new directory(folder)
```bash
mkdir <new_directory_name>
```
5. `rmdir` - Remove an empty directory
Will not remove the directory if it contains any files.
```bash
rmdir <directory_name>
```
6. `rm` - remove files or directories(with it's content)
```bash
rm file.txt #remove a file
rm -r <directory_name> #remove the directory and it's contnet
```
7. `cp` - copy files and directories
- Copying between two file
```bash
cp srcFile.txt destFile.txt #copy srcFile content into destFile
```
- Copy files to a directory
```bash
cp srcFile1 srcFile2 srcFile3 ... DestinationDirectory
#mentioned file(s) will be copied to the destination mentioned at the end of the command in the same names.
```
- Copy directories : use `-R` option used to indicate recursive copying
```bash
cp -R srcDirectory destDirectory
```
If `destDirectory` doesn't exist, it will be created and `srcDirectory`'s files will be copied to it. 
If `destDirectory` exist already, `srcDirectory` will be copied as a sub-directory in the `destDirectory`.
8. `mv` - move rename files
```bash
mv oldName.txt newName.txt #rename a file
mv file.txt /new/location/ #move a file to a new destination
```
9. `touch` - create a new empty file
```bash
touch newFile.txt
```

### User and permission management
1. `whoami` - show current user
2. `who` - show logged -in users
3. `chmod` - (change mode)Change file permission

| Operator | Definition        |
| -------- | ----------------- |
| +        | Add permission    |
| -        | Remove permission |

| Letter | Definition         | Octal mode |
| ------ | ------------------ | ---------- |
| r      | Read permission    | 4          |
| w      | Write permission   | 2          |
| x      | Execute permission | 1          |

| Reference | class      |
| --------- | ---------- |
| u         | Owner      |
| g         | Group      |
| o         | Other      |
| a         | All(above) |
- When permissions mentioned in a number, each digit represent,
	Owner
	Group
	Other
Ex:
```bash
chmod 755 script.sh
```
`755`
	7 = (4+3+1) : **Owner** has Read, Write, Execute permissions
	5 = (4+1) : **Group** has Read & Execute permissions
	5 = (4+1) : **Others** has Read & Execute permissions
Ex: 
```bash
chmod u+rwx script.sh #R,W,Execute permissions to the owner
chmod go-w script.sh #Remove W persmission for group and other
chmod u+rw,go+r script.sh #R,W for the owner, Read only for the group and other
```
4. `chown` - Change file owner
5. `passwd` - Change the user password
### Process and System monitoring
1. `ps` - Show running process
```bash
ps #Displays processes associated with the current terminal
ps aux #Displays a comprehensive list of all processes
```
2. `top` / `htop` - Monitor system processes in real-time
3. `kill` - Terminate a process
```bash
kill <processID> #get the ID using $ps command
```
4. `uptime` - Show how long the system has been running
5. `df -h` - show disk space usage
6. `df -sh folder/` - Show size of a directory
### Networking

2. `ifconfig` - show network interfaces
3. `netstat -tulnp` - Show open ports
4. `wget` - Download a file
