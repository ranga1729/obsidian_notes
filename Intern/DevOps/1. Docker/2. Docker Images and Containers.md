- **Docker image is a template that which acts as a snapshot or blueprint of the libraries and dependencies required inside a container for an application to run.**
- An image contains,
	1. the code
	2. a runtime
	3. libraries
	4. dependencies
	5. environment variables 
	6. config files
- **Container is an actual running instance of an docker image.** 

> [!NOTE] An analogy
> Docker image is like a recipe for baking a cake. It includes all the ingredients and steps. 
> A docker container is the actual cake you bake from that recipe.


Docker Hub : https://hub.docker.com/

****
#### Commands
1. To pull a docker image from docker hub
```bash
docker pull [package_name]
```
![[Pasted image 20250424225456.png]]

2. To see a list of pulled images
```bash
docker images
```
![[Pasted image 20250424225541.png]]
	CREATED : Image's latest release date by the original owner
![[Pasted image 20250424225733.png]]

3. To create a container using an image
```bash
docker run -d [image_name:version]
```
![[Pasted image 20250424230251.png]]
	`-d` : Detach mode. Container start to run in the background.
	Mentioning the version is optional and default to 'latest'.
	Able to use `--detach` instead of `-d`.
This returns the container ID.

4. To see the list of running containers.
```bash
docker container ls
```
![[Pasted image 20250424230442.png]]
	CREATED : Created data by us.
	NAMES : Random name assigned to the container by docker.
![[Pasted image 20250424230646.png]]

Another command to see running list,
```bash
docker ps
```
![[Pasted image 20250425191641.png]]

5. To stop a running docker image,
```bash
docker stop [container_ID]
```
