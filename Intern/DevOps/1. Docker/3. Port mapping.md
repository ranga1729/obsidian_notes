**Port mapping in docker is the process of connecting a port on your host machine to a port inside a docker container.** 
Containers run in isolated environment, so by default you can't access their internal services from your host machine unless you explicitly map the ports.

To map ports,
```bash
docker run -p <host_port>:<container_port> <image>
```
	You can use --publish instead of -p
Ex:
![[Pasted image 20250425193253.png]]
	`0.0.0.0:8080->80/tcp` means our local machine's 8080 port is now mapped to the containers port 80.

#### Multiple post exposing
Use multiple `-p <host_port>:<container_port>` to map multiple ports.
```bash
docker run -p <host_port>:<container_port> -p <host_port>:<container_port> <image>
```

Ex: 
![[Pasted image 20250425211305.png]]
	Now both `8080` and `3000` are mapped to the port 80 of the container.
