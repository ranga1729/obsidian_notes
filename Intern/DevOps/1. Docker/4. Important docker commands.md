1. To check running containers.
```bash
docker ps
//OR
docker container ls
```

2. To check all containers.
Use the `-a` flag.
```bash
docker ps -a
```
![[Pasted image 20250425211848.png]]

3. To check only the ID of running containers.
```bash
docker ps -q
```
You can combine flags.
Ex: To check ID of all containers.
```bash
docker ps -aq
```
`-a` : all
`-q` : filter IDs
![[Pasted image 20250425212300.png]]

3. To remove an container.
```bash
docker rm <container_ID>
```
Ex:
![[Pasted image 20250425212621.png]]

You are not allowed to remove a running container. 
![[Pasted image 20250425212751.png]]
Either you stope it and then remove it.
Or you can use `-f` flag to force remove it.
![[Pasted image 20250425213210.png]]

4. Remove all instance at once
We can nest a docker command using `$(<command>)`.
Ex:
```bash
docker rm -f $(docker ps -aq)
```
![[Pasted image 20250425213706.png]]
	`docker ps -aq` : get all instance IDs.
	`docker rm -f` : force remove containers.
