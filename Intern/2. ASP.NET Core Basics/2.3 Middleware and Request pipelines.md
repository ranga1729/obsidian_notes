Middleware is software that's assembled into an app pipeline to handle requests and responses. 
Each component,
1. Choose whether to pass the request to the next component in the pipeline.
2. Can perform work before and after the next component in the pipeline.
![[Pasted image 20250310001354.png]]

Middleware can,
- Handle incoming HTTP requests
- Modify the request or response
- Pass the request to the next middleware in the pipeline
- Short-circuit the pipeline(return a response without passing the request further)

Middleware components are added to the pipeline in the `Configure` method of the `Program.cs`

****
#### Request Pipeline in ASP.NET Core
The request is a sequence of middleware components that process incoming HTTP requests and generate responses. 
The order in which middleware components are added to the pipeline determines the order in which they are executed. 

Steps,
1. Incoming request: Request enters the pipeline and processed by the first middleware. 
2. Each middleware can perform operations on the request and decide whether to pass it to the next middleware.
3. The response is generated and flows back through the middleware in reverse order.
4. Outgoing Response: The response is sent back to the client.
![[middleware-pipeline.jpg]]
- `Endpoint` middleware in ASP.NET Core is responsible for routing incoming requests to the appropriate endpoint(ex: controller action).
****
#### Creating a custom middleware
1. Define a class with an `Invoke` or `InvokeAsync` method.
```C#
public class LoggingMiddleware
{
    private readonly RequestDelegate _next;

    public LoggingMiddleware(RequestDelegate next)
    {
        _next = next;
    }
    public async Task InvokeAsync(HttpContext context)
    {
        // Log the incoming request
        Console.WriteLine($"Request received: {context.Request.Path}");
        // Call the next middleware in the pipeline
        await _next(context);
        // Log the outgoing response
        Console.WriteLine($"Response sent: {context.Response.StatusCode}");
    }
}
```

2. Register middleware in the pipeline.
Register in the `Configure` method of the `Program.cs`
```C#
public class Startup
{
    public void Configure(IApplicationBuilder app, IWebHostEnvironment env)
    {
        if (env.IsDevelopment())
        {
            app.UseDeveloperExceptionPage();
        }
        app.UseMiddleware<LoggingMiddleware>(); // Add custom middleware to the pipeline
        app.UseRouting(); // this is a built-in middleware
        app.UseEndpoints(endpoints =>
        {
            endpoints.MapGet("/", async context =>
            {
                await context.Response.WriteAsync("Hello, Middleware!");
            });
        });
    }
}
```

****
Built-in middleware,
- `UseRouting()`: Enables routing.
- `UseAuthentication()`: Enables authentication.
- `UseStaticFiles()`: Serves static files.
- `UseExceptionHandler()`: Handles exceptions.
