Both frameworks are developed by Microsoft for building web applications and services.
#### ASP.NET
Mature web framework that has been around since the early 2000s.
Build on the .NET Framework. 
Primarily used for building web applications, web APIs and dynamic websites.

#### ASP.NET Core
Modern, cross-platform, high-performance framework for building web applications and APIs. 
A complete re-design of ASP.NET and a complete new framework.

Features,
1. Cross-platform
	- Built on .NET Core(unified into .NET5+) & not the .NET Framework.
2. Optimized for performance and can handle more req per second compare to ASP.NET.
3. Unified framework
	- Combines MVC, Web API and Razor pages into a single framework.
	- Support modern practices including dependency injection, middleware and modular architecture. 
4. Open source
5. Can be hosted on IIS, Kestrel, Docker or cloud platforms like Azure.

Example use cases,
1. modern web application and APIs.
2. Cross-platform applications.
3. microservices and cloud-native applications.

Ex:
```C#
using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;
using Microsoft.Extensions.Hosting;

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();
app.MapGet("/". () => "Hello, World!");
app.Run();
```
