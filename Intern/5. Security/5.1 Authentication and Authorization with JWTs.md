JWT = Jason Web Token

JWT is a industry standard mechanism for securely transmitting information between parties as a compact, self-contained token.

Benefits, 
- Stateless Authentication 
	No need to store session da the server. 
- Compact & Fast
	Transferred in headers.
- Secure
	Optionally encrypted.
#### Authentication vs. Authorization
**Authentication**
	The process of verifying the user.
	User provide credentials and if they are valid, the server issues an access token(JWT).
**Authorization**
	Determine what resources the authenticated user can access.
	The JWT contains **user roles**(ex: admin, user) and permissions.
	Every API request include the token, which the server verifies before granting access.

Ex: 
Issue Tokens
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5c...",
  "refresh_token": "c29tZXJhbmRvbG9uZ3JlZnJlc2..."
}
```

Sending API Requests
```http
GET /api/protected-data
Authorization: Bearer <access_token>
```

### How JWT authentication & authorization work in a web application

#### 1. User login
1. The user enters credentials in the React login form.
2. The credentials are sent via Axios to the ASP.NET backend.
3. The backend,
	- Validates credentials against the database.
	- If correct, generates a JWT **access token**(short-lived) and a **refresh token**(long-lived)
	- Sends both token to the client.
React send login request,
```js
axios.post("https://api.example.com/auth/login", {
  email: "user@example.com",
  password: "password123"
})
.then(response => {
  localStorage.setItem("accessToken", response.data.access_token);
  document.cookie = `refreshToken=${response.data.refresh_token};
  Secure; 
  HttpOnly`;
});
```
ASP.NET Backend generates JWT
```C#
var tokenHandler = new JwtSecurityTokenHandler();
var key = Encoding.UTF8.GetBytes("your_secret_key");
var tokenDescriptor = new SecurityTokenDescriptor
{
    Subject = new ClaimsIdentity(new[] { new Claim(ClaimTypes.Name, user.Id.ToString()) }),
    Expires = DateTime.UtcNow.AddMinutes(15), // Short-lived
    SigningCredentials = new SigningCredentials(new SymmetricSecurityKey(key), SecurityAlgorithms.HmacSha256Signature)
};
var token = tokenHandler.CreateToken(tokenDescriptor);
var accessToken = tokenHandler.WriteToken(token);
var refreshToken = GenerateRefreshToken(); // Long-lived, stored securely
```

#### 2. Client request a protected resource
1. The react frontend retrieves the access token from `localstorage`
2. It sends the token in the `Authorization` header using Axios.
3. The ASP.NET backend verifies the JWT before allowing access.
React makes an API
```js
axios.get("https://api.example.com/user/profile", {
  headers: { Authorization: `Bearer ${localStorage.getItem("accessToken")}` }
})
.then(response => console.log(response.data))
.catch(error => console.error(error));
```
ASP.NET middleware validates JWT
```C#
services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = new SymmetricSecurityKey(Encoding.UTF8.GetBytes("your_secret_key")),
            ValidateIssuer = false,
            ValidateAudience = false
        };
    });
```

#### 3. Handling token expiration(Refresh flow)
1. If the access token expires, the API returns a `401` unauthorized.
2. The frontend sends the **refresh token**(stored in an HTTP-only cookie) to request a new access token. 
3. The ASP.NET backend verifies the refresh and issues a new access token.
React refresh request
```js
axios.post("https://api.example.com/auth/refresh", {}, { withCredentials: true })
.then(response => localStorage.setItem("accessToken", response.data.access_token))
.catch(() => {
  // Redirect to login if refresh token fails
  window.location.href = "/login";
});
```
ASP.NET generates a new access token
```C#
[HttpPost("refresh")]
public IActionResult RefreshToken()
{
    var refreshToken = Request.Cookies["refreshToken"];
    var storedToken = GetStoredRefreshToken(); // Verify stored token

    if (refreshToken != storedToken)
        return Unauthorized(new { message = "Invalid refresh token" });

    var newAccessToken = GenerateJwtToken();
    return Ok(new { access_token = newAccessToken });
}
```

#### 4. User Log out
1. The frontend removes the access token from `localstorage`
2. The backend invalidates the refresh token.
React Logout functions
```js
axios.post("https://api.example.com/auth/logout", {}, { withCredentials: true })
.then(() => {
  localStorage.removeItem("accessToken");
  document.cookie = "refreshToken=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/;";
  window.location.href = "/login";
});
```
ASP.NET invalidates refresh token
```C#
[HttpPost("logout")]
public IActionResult Logout()
{
    Response.Cookies.Delete("refreshToken");
    return Ok(new { message = "Logged out successfully" });
}
```

### Best practices
**Access Token Security**
- Keep it short-lived(ex: 15-30 minutes)
- Store it in memory(not to local storage, to prevent XSS attacks)
- Use HTTPS to encrypt token transmission.

**Refresh Token security**
- Stores it securely.(ex: http only, secure cookie)
- Rotate the refresh token upon each use.(prevent reuse attacks)
- Implement token revocation. (ex: blacklist compromised token)

**JWT signing and verification**
- Sign JWT using `HS256(HMAC)` or `RS256(RSA asymentric key)`
- Validate JWTs on each request(to prevent forged tokens)
