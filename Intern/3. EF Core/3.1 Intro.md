EF Core is version of the popular **Entity Framework**, a data access technology for .NET.
It's an ORM(Object Relational Mapper) enables developers to work with databases using .NET objects.
Supports, 
- SQL Server
- SQLite
- PostgreSQL
- MySQL and more.
#### How EF Core works ?
It maps .NET objects(entities) to database tables and allows you to,
- Query data using LINQ
- Insert, update and delete data using .NET objects
- Manage database schema changes using migrations.
#### Core components of EF Core
1. **DbContext**
	Represent a session with the database and is used to query and save data.
	It manages entities and their relationships.
2. **DbSet**
	Represent a collection of entities.(a table in the database)
3. **Entities**
	Plain .NET classes that map to a database table.
4. **Migrations**
	A feature to keep the database schema in sync with the application's data model.


> [!NOTE] Code-First vs Database-First
> **Code-First** : Define models in code and generate the database
> **Database-First** : Generate models from an existing database
> EF Core support both approaches.

****
#### Code-First Approach
Define your data model using .NET classes then EF Core will generates the database schema from these classes.

1. Define Entities
Ex: 
```C#
//Product.cs
public class Product
{
	public int Id { get; set; } //primary key
	public string Name { get; set; }
	public decimal Price { get; set; }
}
```

2. Create `DbContext` class that includes `DbSet<T>` properties for each entity.
Ex: 
```C#
//AppDbContext.cs
public class AppDbContext : DbContext
{
	public DbSet<Product> Products { get; set; }

	protected overrride void OnConfiguring(DbContextOptionsBuilder optionsBuilder) 
	{
		//Configure the database provider and connection string
		optionsBuilder.UseSqlServer("Server=myServer;Database=myDb;User Id=myUser;Password=myPassword;");
	}
}
```

3. Run EF Core migration to create and update the database schema.
```bash
dotnet ef migration add <migration_name>
dotnet ef database update
```

****
#### Query and Save data
Use the `DbContext` to interact with the database.
```C#
using (var context = new AppDbContext())
{
	var product = new Product
	{
		Name = 'Laptop',
		Price = 1200.00;
	};
	context.Products.Add(product);
	context.SaveChanges();
var products = context.Products.Where(p => p.Price > 1000).ToList();
}
```
