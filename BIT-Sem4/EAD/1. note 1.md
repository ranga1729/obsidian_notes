## 📄 1. **JSP (JavaServer Pages)**

### ✅ **Common JSP Syntaxes**

|Syntax|Purpose|Example|
|---|---|---|
|`<% ... %>`|Scriptlet – raw Java code|`<% int x = 5; %>`|
|`<%= ... %>`|Output expression value|`<%= user.getName() %>`|
|`<%! ... %>`|Declaration (like class-level variables/methods)|`<%! int count = 0; %>`|
|`${...}`|EL (Expression Language) for printing|`${user.name}`|
|`<jsp:useBean>`|Instantiates a JavaBean|`<jsp:useBean id="user" class="beans.UserBean" scope="request"/>`|
|`<jsp:setProperty>`|Sets a property in the bean|`<jsp:setProperty name="user" property="name" value="Ravi"/>`|
|`<jsp:getProperty>`|Gets a property value|`<jsp:getProperty name="user" property="name"/>`|
|`<%@ page %>`|Page directive|`<%@ page contentType="text/html" %>`|
|`<%@ include file="..." %>`|Static include|`<%@ include file="header.jsp" %>`|
|`<jsp:include page="..." />`|Dynamic include|`<jsp:include page="footer.jsp"/>`|
|`<c:if>`, `<c:forEach>`|JSTL tags (requires JSTL library)|`<c:if test="${user != null}">Welcome!</c:if>`|

## ⚙️ 2. **Servlets**

### ✅ **Common Annotations**

|Annotation|Purpose|
|---|---|
|`@WebServlet("/path")`|Declares a servlet and its URL pattern|
|`@WebInitParam(name = "...", value = "...")`|Set servlet initialization parameters|
|`@WebListener`, `@WebFilter`|Declare listeners or filters (optional features)|
|`@MultipartConfig`|For file upload handling|

### ✅ **Common Methods**

|Method|Description|
|---|---|
|`doGet(HttpServletRequest req, HttpServletResponse res)`|Handles GET requests|
|`doPost(...)`|Handles POST requests|
|`getServletContext()`|Gets global context|
|`getRequestDispatcher("page.jsp").forward(req, res)`|Forward to a JSP|
|`response.sendRedirect("page.jsp")`|Redirect|
|`request.getParameter("name")`|Get form input|
|`request.setAttribute("key", value)`|Pass data to JSP|

### ✅ **Example Snippet**

```java
@WebServlet("/hello")
public class HelloServlet extends HttpServlet {
    protected void doGet(HttpServletRequest req, HttpServletResponse res)
        throws ServletException, IOException {
        req.setAttribute("message", "Hello from Servlet");
        req.getRequestDispatcher("hello.jsp").forward(req, res);
    }
}
```

## 🫘 3. **JavaBeans**

JavaBeans follow a naming convention, and usually don't need annotations unless integrated with frameworks like CDI or JSF.

### ✅ **JavaBean Requirements**

|Rule|Example|
|---|---|
|Public no-arg constructor|`public UserBean() {}`|
|Private fields|`private String name;`|
|Public getters/setters|`public String getName()`, `public void setName(String name)`|
|Serializable (optional but recommended)|`implements Serializable`|

### ✅ **Used in JSP with:**

- `<jsp:useBean>`, `<jsp:getProperty>`, and `<jsp:setProperty>`
    

### ✅ **Optional Annotations (If using CDI or JSF)**

|Annotation|Usage|
|---|---|
|`@Named("beanName")`|CDI/JSF name injection|
|`@RequestScoped`, `@SessionScoped`|Bean lifespan control|
