
## 🎯 Quick Summary

|Type|Maintains Client State?|Use Case|Annotation|
|---|---|---|---|
|**Stateless Bean**|❌ No|Reusable service (e.g., login, calculation)|`@Stateless`|
|**Stateful Bean**|✅ Yes|Session-specific logic (e.g., shopping cart)|`@Stateful`|

---

## 🔧 Real-World Analogy

- **Stateless Bean** = Like a **calculator** — you give it numbers, it gives you a result. It forgets everything after.
    
- **Stateful Bean** = Like a **shopping cart** — remembers what items you've added until you finish shopping.
    

---

## ✅ Example: Shopping Cart

Let’s create a simple Java EE example comparing both.

---

### 🧩 1. **Stateless Bean**

```java
import jakarta.ejb.Stateless;

@Stateless
public class PriceCalculatorBean {

    public double calculateTotal(double price, int quantity) {
        return price * quantity;
    }
}
```

**Usage (Client or Servlet):**

```java
@Inject
PriceCalculatorBean calculator;

double total = calculator.calculateTotal(100.0, 3);
// total = 300.0
```

> This bean doesn't remember any previous calls or data. It performs logic and forgets.

---

### 🧩 2. **Stateful Bean**

```java
import jakarta.ejb.Stateful;
import java.util.ArrayList;
import java.util.List;

@Stateful
public class ShoppingCartBean {
    private List<String> cart = new ArrayList<>();

    public void addItem(String item) {
        cart.add(item);
    }

    public List<String> getItems() {
        return cart;
    }

    public void clearCart() {
        cart.clear();
    }
}
```

**Usage (Client or Servlet):**

```java
@Inject
ShoppingCartBean cart;

cart.addItem("Book");
cart.addItem("Laptop");

List<String> items = cart.getItems(); // ["Book", "Laptop"]
```

> This bean **remembers** your cart items across multiple method calls during the session.

---

## ⚠️ Lifecycle Differences

|Feature|**Stateless**|**Stateful**|
|---|---|---|
|Memory|Lightweight, easily pooled|Heavier, tied to a specific client|
|Scalability|High|Lower (per-client instance)|
|Persistence|No conversational state|Holds conversational state|
|Suitable for|Simple service methods|Workflows, sessions, shopping carts|

---

## 🧠 Summary

- Use **`@Stateless` beans** when you want **fast, scalable, reusable logic**.
    
- Use **`@Stateful` beans** when you want to **maintain state between calls** from a particular client (like during a login session or shopping).
