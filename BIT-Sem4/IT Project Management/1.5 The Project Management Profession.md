### History of Project Management
Manhattan Project is to be considered the first project to use 'modern' project management.
	This was a three years project(in 1946)
	Total budget : $2 Billion
	Had separate project and technical managers.

PMI(Project Management Institution) provides certification as a Project Management Professional(PMP).
PMP requires 
	Sufficient documented experience
	Agreeing to follow a code of ethics
	Passing the PMP exam
### Ethics in Project Management
Project managers often face ethical dilemmas.
PMP certification applicants must agree to the PMP code of professional conduct. 
### Project Management Software
Categories of tools,
1. Low-end
	Handle single or smaller projects.
	Cost: under $200 per user
2. Midrange
	Handle multiple project and users.
	Cost: $200 - $500
3. High-end
	Enterprise project management software.
	Often licensed on per user basis.

Enterprise PM software integrates information from multiple projects to show the status of active, approved and future projects an entire organization.
It also provides detailed information on each project. 

### Project Management Tools and Techniques
1. **Project Charter and Work Bench Structure(WBS)** - Scope Management
	Project charter : Outlines the project purpose
	WBS : Breaks down the project into smaller, manageable tasks
	WBS is derived from the project charter and provide a roadmap for execution.
	![[Pasted image 20250326110507.png]]
2. **Gantt charts, PERT Charts, Critical path analysis(CPA), critical chain scheduling** - Time Management
	Gantt charts : Visually represents a project's schedule, tasks, timelines, dependencies and milestones using horizontal bars.
	![[Pasted image 20250326110942.png]]
	PERT Charts : Similar to Gantt charts, but structured differently. PERT uses network diagram to chow charts unlike the horizontal bars in the Gantt chart.
	![[Pasted image 20250326111158.png]]
	Critical Path Analysis(CPA) : Used to identify the longest sequence of interdependent tasks(the critical path) that determines a projects minimum completion time. 
	![[Pasted image 20250326111552.png]]
	Critical Chain scheduling : Used to prioritize resource utilization and identifies the critical chain of tasks.
	![[Pasted image 20250326112250.png]]
3. **Cost estimates and Earned value management chart** - Cost Management
	Cost estimates : An approximation of the total cost of a project, program, or operation.
	![[Pasted image 20250326112501.png]]
	Earned value management chart : Displaying earned value management metrics over time. Typically, the chart has lines that represent budget (planned project cost), actual cost and earned value, which is a measure of how much progress has been made.
	![[Pasted image 20250326112743.png]]
