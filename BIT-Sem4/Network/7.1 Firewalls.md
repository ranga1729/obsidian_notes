### Firewalls
![[Pasted image 20250528115531.png]]
- Firewall is a perimeter protection device. 
- It places in a network where all traffic has to go through this. 
- Firewall uses different mechanism to filter traffic, most are rule based.

Mechanisms used in Firewalls,
1. Packet filter 
	- Whitelisting : blocking all traffic and only allowing what is acceptable 
	- Blacklisting : blocking what is not accepted and allowing others
	Filtering based on a combination of IP addresses and ports including source IP, destination IP, source port, destination port.
2. DMZ(De-Militarized Zone)
	DMZ is a zone lies outside of the security perimeter. 
	It makes sure those who need services are served outside the main perimeter. 
	Specific rules may exist to allow internal computers to connect to servers located in the DMZ for management purposes

Types of firewalls,
1. Stateful firewall
	Keep track of connections between two computers rather than just inspecting individual packets. This helps to impose rules more effectively.
	Ex: allowing HTTP traffic to internal network only if the connection request was made by an internal user
2. Application level gateways
	Designed to examine application-level protocols to check particular application activity. 
	Used for,
	- Distinguish different uses of the same protocol.
		Ex: Differentiating HTTP traffic from web browsing and peer-to-peer file sharing.
	- Prevent specific actions
		Ex: emailing sensitive documents to the outside.

Limitations of firewalls,
- Intruders can put in false source addresses to bypass rules. 
- Only provide a single perimeter of defense even in scenarios where layered security is required. 
- May not be able to prevent all DoS/DDoS attacks.
