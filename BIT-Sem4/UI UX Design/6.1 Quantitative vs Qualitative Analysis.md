#### Quantitative Analysis
> [!NOTE] Description
> **Quantitative analysis** involves examining numerical data to uncover patterns, relationships, or trends. It uses statistical methods and produces measurable results (e.g., averages, percentages, correlations, magnitudes)

Quantitative analysis uses different types of graphs/charts for representations.
Ex: Bar graphs, Pie charts, Scatter plots.

Types of quantitative data,
1. Counter
2. Measurements of physical objects
3. Sensory calculation
4. Projection of data
5. Quantification of qualitative entities

*****
#### Qualitative Analysis

> [!NOTE] Description
> **Qualitative analysis** deals with non-numerical data like text, audio, or images. It focuses on understanding meanings, experiences, or concepts through methods like interviews, open-ended surveys, and thematic analysis.

Qualitative analysis focuses on the nature of something and can be represented by themes, patterns and stories.

****

### Qualitative data as NUMBERS
Qualitative data also can be converted into numbers.
This process is called **coding** or **quantification**, where categories or themes are assigned numerical values for analysis. 

Ex: In a survey, people answer the question: _"How satisfied are you with our service?"_ with responses like very satisfied, satisfied,... These responses can be converted into a number. 
- Very satisfied = 5
- Satisfied = 4
- Neutral = 3
- Dissatisfied = 2
- Very dissatisfied = 1
This allows the data to be analyzed statistically (e.g., calculating the average satisfaction score).
