### Interaction Design
![[Pasted image 20250326180850.png]]
Interaction design is the design of the interaction between users and products and is a component within UX design.

#### Double diamond framework for getting users involved
![[Pasted image 20250326181440.png]]
Double diamond framework is a design thinking model that guides designers through a structured, iterative process of problem identification and solution development.

1. Discover : Understand the problem deeply with people who are affected by it.
2. Define : Frame the problem in a clear and concise way based on the insights gathered in the discover phase. 
3. Develop : Generate and explore a wide range of potential solutions to the defined problem.
4. Deliver : Refine and implement the best solution, testing them in a real-world context.
#### Getting users involved in design
- Design is also a trade-off.
	Ex: Deciding how much choices will be given to users vs How much directions the system should offer. 
- Designs should be expressed in a form that allows review, revision and improvement.
	Produce a series of sketches.
	Write descriptions in natural language.
	Draw a series of diagrams.
	Build a prototype.
	
Mistakes,
- Potential users and their context can be misunderstood.
- Usability and user experience goals can be overlooked.

#### Understanding the problem space
**Problem space** refers to the initial phase of understanding and defining a problem, encompassing the need and context of users, before focusing on solution. 

Before designing anything, first understands the problem by,
- Knowing how things currently work
- Identifying why a change is needed.
- Seeing how the change will make things better
Understanding the problem should be a team effort involving different perspectives. 
#### Importance of involving users
Involving users to the UX design process if the best way to ensure that the end product is usable. an it helps to make sure users expectations of the new product are realistic.

#### Proof of concepts
Proof of concept(POC) means demonstrated the feasibility of a proposed product, method or idea. 
This is a way for you to prove that your idea will work in the real world, so stakeholders and investors feel comfortable moving forward with the project.
POC is important when designing new ideas. 
#### Generating research questions
Asking questions, reconsidering assumptions, and articulating concerns and standpoints are central aspects of the early ideation process.
#### Conceptualizing interactions
- Be clear about the underlying assumptions and claims
	Assumptions : Taking something for granted without proof. Serving a foundation for the claim.
	Claims : Statements to be true when it is still open to question.
- Understanding the assumptions and claims.
	Ex:
		Are there problems with an existing product or user experience? 
		If so, what are they? 
		Why do you think there are problems?
		What evidence do you have to support the existence of these problems?
		How do you think your proposed design ideas might overcome these problems?

#### Conceptual models 
A conceptual model is a simplified, high-level representation of a system or concept, often visual, that helps to understand and communicate complex ideas by focusing on key elements and relationships.

Fundamental modeling practices(ex: UML designs) by their very nature forms of conceptual model.
![[Pasted image 20250326191831.png]]

**By creating products that echo conceptual models, designers build on existing knowledge and frameworks, making it easier for the users to learn how to use the new product.**

Ex:
The Xerox Star
![[Pasted image 20250326192412.png]]
Designed as a office system.
Based on a conceptual model that included the familiar knowledge of an office.
Ex: 
	Dragging a document was equivalent to moving a piece of paper.
	Putting a document in a folder equivalent to placing a physical document into a physical cabinet.

### Interface Metaphors
Metaphor : a thing regarded as representative or symbolic of something else.

Metaphors are important in conceptual modeling.
They can be used to map familiar object to an unfamiliar object. 
Metaphors can be used as a tool in the design process to understand new topic areas or as a means to create new ideas about familiar subjects.

Ex: 
1. Most well known metaphor in UX is the desktop metaphor. 
	Represents the user interface in a way that is similar to interactions with objects on a real desktop. Opening document into a window similar to a paper copy placed on to the desktop.
2. Book metaphor : for hypertext, online catalogues
3. Filing cabinets : For online documentations
4. Office metaphor : For collection of documents
5. Library metaphor : For large collections of documents or archives
6. Animated agent metaphor(Windows XP Clippy) : for guidance, recommendation, persuasion

### Interaction Types
Types,
1. Instructing
	User giving direct commands to the system.(ex: print or save a document)
	Commands will be given by typing, selecting options, touching or speaking.
	![[Pasted image 20250327095846.png]]
2. Conversing
	Users engage in a dialogue with the system, asking questions and receiving answers. (ex: help system, System agents, chat bots)
	![[Pasted image 20250327095903.png]]
3. Manipulating
	User interacting with virtual items or environment. (ex: dragging, dropping items, resizing windows) User may user physical controllers(ex: mouse), gestures(ex: mobile phone gestures) to manipulate. 
4. Exploring
	Users navigate and browse through information or a virtual environment. (ex: browsing website or the file system)
5. Responding
	System initiate a request for a user to respond. (ex: notifications)
