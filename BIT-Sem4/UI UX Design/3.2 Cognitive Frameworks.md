Refers to a structured ways of understanding how user perceive and interact with digital interfaces based in cognitive psychology principles. It helps designers create user-friendly experience by considering how the human mind works. 

Ex: 
- Mental models
- Gulfs of execution and evaluation
- Information processing
- Distributed cognition
- External cognition
- Embodied interaction

#### 1. Mental models
Users from expectations based on past experience. 
If a design align with their mental model, they understand it faster. 
The more they understand the product, their mental model develops over the time. 

Tip: Use familiar UI patters.
Ex: shopping cart icon for checkout, red color for delete button

**Mental Model vs Conceptual Model**
![[Pasted image 20250402122743.png]]
- Mental model : Represents a person's internal understanding of how something works. 
- Conceptual model : The actual design that is given to the user through the interface of the product. The designers representation of how a system is intended to function. 

**Bridging mental models and conceptual models**
- Clear and easy-to-follow instructions
- Appropriate online help where users can ask how to so something
- Background information on how to make most of the functionality provided
- Making interfaces intuitive(Transparency)
- Affordances(characteristics of an object or environment that prompt or promote a specific use or interaction) of what actions an interface allows.
	Door know afford pulling, Button afford clicking
- Research and understand customer expectations first.
- Use familiar terminology to users. 
- Leverage interface patterns.
- Leverage familiar mental models from the natural world.
- Educating users. 
- Use user journeys.
#### 2. Gulfs of Executions and Evaluations
Describes the challenges users face when interacting with a system.

- Gulf of Execution(Doing the action) : Refers to the gap between user's goals the systems affordances(what actions are available). Represents how easy or difficult it is for a user to figure out how to perform an action.
	Ex: User wants to save a file but can't find the button. 
	Fix: Make actions discoverable, intuitive and aligned with users expectations.
- Gulf of Evaluation(Understanding the result) :  Refers to the gap between user's expectations and system feedbacks. Represent how easy for users to understand what happened after taking an action. 
	Ex: User clicks on the 'Submit' button and no confirmation message so they don't know if the action worked. 
	Fix: Provide feedbacks. (ex: success message, loading indicator, error alerts)
#### 3. Information processing
Refers to how users perceive, interpret and respond to information presented in an interface. 
Consider mind as an information processor. 
Information is thought to enter and exit the mind through a series of ordered processing stages. 

Human processor model,
![[Pasted image 20250402131526.png]]
Stags, 
1. Input(Perception stage)
	User receive information from the interface through visual, auditory or tactile stimuli. 
	UX Tip : Use clear typography and icons to enhance readability and recognition. 
2. Encoding(Understanding stage)
	The brain translate raw input into information. 
	UX Tip : Present content in an easily digestible format. 
3. Comparison(Processing stage)
	Users compare new information with what they already know.(mental models)
	UX Tip : Use familiar UI patterns.
4. Response selection(Decision making)
	Users decide what action to take based on their understanding of the interface.
	UX Tip : Clear call-to-action buttons(ex: sign up button says "Sign Up")
5. Response execution(Action stage)
	Users interact with the system.
	UX Tip : Ensure affordance(interactive buttons should look clickable)
6. Output(Feedback & Learning)
	Users receive conformation or error messages base on their actions. 
	UX Tip : Show success messages, errors states and progress indications.
#### 4. Distributed Cognition
Distributed cognition refers to how users process and share information across devices, interfaces and teams rather than relying solely in their internal cognitive abilities. 
It includes interactions with external tools, environments and other people. 
Developed to study the nature of cognitive phenomena across individuals and internal/external representations.

Ex: In an Aero plane, pilots, captain and air traffic controller is interacting with each other. 
The pilot and captain interacting with the instruments in the cockpit. 
So the system must be developed considering all of these interactions between users. 
#### 5. External Cognition
![[Pasted image 20250402151349.png]]
Refers to the cognitive process involved when users interact with different external representations such as graphical images, multimedia, VR. 
Main benefits,
- Externalizing to reduce memory load. 
- Computational offloading.
- Annotating and cognitive tracing. 
#### 6. Embodied Interaction
Refers how humans interact with technology through their physical bodies, moving beyond traditional screen-based interfaces to encompass physical actions, gestures, and tangible objects.

Ex: 
	Wearable technology
	Haptic technology
	Tangible user interfaces
