(ex: Smart watches, Smartphones, laptops, smart TVs)

Different types of interfaces have been developed with different features,
- Graphical commands
- Speech commands
- Multimodal 
- Invisible/ambient features
- Mobile intelligent
- Touchless
- Pen-based inputs
- Speech-based inputs
- Gesture based inputs

Default style for majority of interactive computer systems, especially PCs and desktop machines. 
##### Windows
Areas of the screen that behave as if they were independent. 
Can contain text, graphics.
Can be removed, resized.
Can overlap
Scroll bars : Allows user to move the content of the window.
Title bar : Describe the name of the window
##### Widgets
Three aspects, 
- Appearance - how they look
- Interaction - How they behave
- Semantics - What they mean

##### Three dimensional interfaces
Facilitate to develop immersive environment. (ex: VR)
