##### 1. Multimedia
Multimedia interfaces combine different media within a single interface.
Ex:
	graphics
	text
	video
	sound
	animation
	links
Helps to facilitate rapid access to multiple representations of information.
##### 2. VR and AR
VR : Create a simulated environment. Places user inside an experience. User interact with 3D world. 
AR : Three dimensional virtual images appear superimposed over real objects. Typically use head mounts or handheld displays to make computer graphics. 
##### 3. Web Interfaces
Allows the user to interact with content or software running on a remote server through a Web browser.
##### 4. Mobile Interfaces
Allows the user to interact with content or software running on a mobile device. 
##### 5. Embedded Interfaces
Many of the appliances include machines for everyday use in the home (washing machines, microwave ovens, refrigerators, toasters, bread makers, and smoothie makers) now have LED displays.
##### 6. Voice Based Interfaces
A voice user interface (VUI) involves a person talking with a spoken language app (search engine, a train timetable, a travel planner, or a phone service).
Used for inquiring about specific information or issuing a command to a machine
##### 7. Pen Based Interfaces
Enable people to write, draw, select, and move objects on an interface using light pens or styluses.
Interact with tablets and large displays, instead of mouse, touch, or keyboard input, for selecting items and supporting freehand sketching.
##### 8. Touch Interfaces
Single touchscreens : Used in walk-up kiosks. 
	ATMs,
	Cash registers
Multitouch surface : Support a much wider range of more dynamic fingertip actions, such as swiping, flicking, pinching, pushing, and tapping.
##### 9. Gesture based interfaces
Involve moving arms and hands to communicate or to provide information to someone.
How technology can be used to capture and recognize a user’s gestures for input by tracking them using cameras and then analyzing them using machine learning algorithms.

##### 5. Haptic Interfaces
Provides tactile feedback.
Applying vibration and forces to the person, using actuators that are embedded in their clothing or a device that they are carrying, such as a smartphone or smart watch.

##### Robots
- Usage : Part of manufacturing assembly lines, remote investigators of hazardous locations, search and rescue helpers in disasters
- Control : Console interfaces, joysticks and keyboard controls together with cameras and sensor-based interactions
- Interfaces were designed enabling users to steer and move a remote robot effectively with the aid of live video and dynamic maps.
##### Drones
Form of unmanned aircraft that are controlled remotely.

##### 9. Brain Computer Interfaces(BCI)
- Provide a communication pathway between a person’s brain waves and an external device.
Every time we think, move, feel, or remember something, these neurons become active. Small electric signals rapidly move from neuron to neuron, which to a certain extent can be detected by electrodes that are placed on a person’s scalp. The electrodes are embedded in specialized headsets, hairnets, or caps.

##### 10. Smart Interfaces : Combination of multiple interfaces
The device has some intelligence and it is connected to the Internet.
Features :
	Designed to interact with users and other devices. 
	Connected to a network
	Automated
	Context-aware
Ex: Smartphone, smartwatch, smart building, smart home, or smart appliance
##### 11. Natural Interfaces
A **natural user interface(NUI)** is designed to allow people to interact with a computer in the same way that they interact with the physical world.
Enable users to speak to machines, stroke their surfaces, gesture at them in the air, dance on mats that detect feet movements, smile at them to get a reaction.
