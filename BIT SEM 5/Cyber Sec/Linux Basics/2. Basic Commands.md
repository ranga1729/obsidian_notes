1. `pwd`
Stands for "Present/Print working directory"

2. `whoami`
To find the current user.

3. `cd`
Change directory

4. `cd ..`
To move up one level in the file system(towards the root of the file hierarchy).
	`..` : one level
	`../..` : two levels
	`../../..` : three level

5. `ls`
To list the content of the current directory(both files and directories).
	`ls -l` : (list long) to see more details about the current directory including permission, owner, size and last modified data
![[Pasted image 20250910095720.png]]
Hidden files are not typically show up in the `ls` or `ls -l` command.
	`ls -a` : To list the directory with hidden details
	`ls -la`(or `ls -l -a`) : To see detailed list with hidden files.
![[Pasted image 20250910100144.png]]

6. `--help` flag
Nearly every command/program has a dedicated help file.
Some commands support its short version `-h` and `-?`
Ex:
```sh
aircrack-ng --help
nmap -h
```

> [!NOTE] `--` and `-` convention
> Use double dash (`--`) before word options.
> Use single dash (`-`) before single-letter options. 

7. `man`
Most commands/applications have a manual page with more information than `--help` option. Usually provides a description, synopsis and examples of the command.

##### Finding stuff
7. `locate` 
Use this command with a keyword denoting what you want to search. This will go through the entire file system and locate every occurrence of that keyword.
![[Pasted image 20250910101853.png]]
=="locate" uses a database that is usually only updated once a day.== 
So if you just create a file few minutes ago, it might not appear in the list until the next day. 

8. `whereis`
Use if you are looking for  a binary file. 
It provides binary, source file and the man pages if they are available.
![[Pasted image 20250910102434.png]]

9. `which` 
Similar to `whereis` but only returns the location of the binaries in the PATH variables in linux.
![[Pasted image 20250910102754.png]]

> [!NOTE] PATH variables
> PATH holds the directories in which the operating system looks for the commands you execute at the command line.
> Mostly this includes paths in `/usr/bin` and may include `/usr/sbin` and few others.

10. `find`
More powerful and flexible. 
Capable of beginning from any designated directory. 
Allow multiple parameters,
- name of the file
- date of creation/modification
- the owner
- the group
- permission
Basic syntax,
```sh
find directory options expression
```

Ex:
Search for a file with the name "apache2"(an open source server) starting in the root directory.
```sh
find / -type f -name apache2
```
	type can be 'f' for file or 'd' for directories.

![[Pasted image 20250910112045.png]]

Methods to improve the search,
- Narrow down the search area by correct/possible directory.(Ex: if we are looking for a configuration file, it may be in the `/etc` directory)
- Use wildcards(`* . [] , ?`)
```sh
find /etc -type f -name apache2.\*
```


> [!NOTE] Wildcards
> The `?` wildcard is used to represent a single character. 
> The `[]` wildcard is used to match the characters that appear inside the brackets.
> The `*` wildcard is used to match character(s) of any length.

Ex: A directory has files "cat", "hat", "bat" and "what"
- Search for `?at` would find hat, cat and bat, but not what
- Search for `[b,c,]at` would match cat and bat, but not hat and what.
- Search for `*at` would match cat, hat, bat, and also what.

#### Piping & filtering
`grep` is usually used for filtering for a keyword.
The `grep` command is often used when output is piped from one command to another(Linux allows us to take the output of one command to another command).
We use `|` command for piping.

Ex: 
```sh
ps aux | grep systemd
```
Look for running processes and filter the keyword "systemd"

#### Modifying files and directories
1. `cat` (concatenation)
`cat` is generally used for displaying the content a file, but it can be used to create small files.
- Follow the `cat` command with a redirect(`>`) to create a file.(overwrite if the file is already available)
```sh
cat > name.txt
This is the text going to be saved in the name.txt file created by cat command.
```
- Don't use the redirect symbol just to print the content to the console. 
```sh
cat name.txt
```
- Use double redirect(`>>`) to append more content to the already existing file.
```sh
cat >> name.txt
This is the next line add to the end of the file.
```

2. `touch`
Originally created to change files details such as created and modified dates. 
If the file doesn't exist already, it will create a new file. 
```sh
touch newfile
```

3. `mkdir` (make directory)
Used to create new directories.
```sh
mkdir newFolder
```

4. `cp` (copy)
Used to copy file to a new directory. 
```sh
cp filename.txt filepath/.../destination
```
If you want to rename the copying file, add the new name to the end of the new directory path.
```sh
cp filename.txt filepath/.../destination/test.txt
```

**Linux doesn't have a command solely for renaming files.**

5. `mv` (move)
Used to move a file from one location to another location. 
```sh
mv filename /destination
```
You can use the `mv` to rename files as well.
```sh
mv oldname newname
```

6. `rm` (remove a file)
```sh
rm filename
```
7. `rmdir` (remove directory)
```sh
rmdir dirName
```
`rmdir` will not allow to remove a directory which is not empty. 

If you want to remove the directory with all its content inside,
```sh
rm -r dirName
```
**Be cautious when using this rm -r command.**
