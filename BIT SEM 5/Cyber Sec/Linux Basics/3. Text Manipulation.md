In linux, everything is a file and most of the times, they will be test files. 
(All configuration files are text files)

1. Viewing files
`cat` is usually used to view files in the terminal but it has limitations. 
```sh
cat /etc/snort/snort.conf
```

2. Viewing the head
If you just want to view the head(by default first 10 lines) of the file you can use the head command. 
```sh
head /etc/snort/snort.conf
```
You can change the lines of code using `-<number of lines>` before the file name.
```sh
head -15 /etc/snort/snort.conf
```

3. Viewing the tail
Similar to head command but used to view the tail of the file. (default is 10 line from the end)
```sh
tail /etc/snort/snort.conf
```
To change the lines,
```sh
tail -15 /etc/snort/snort.conf
```

4. Numbering lines
When dealing with very long files, it useful to show the line number at the left corner. 
```sh
nl /etc/snort/snort.conf
```
(This command skip the numbering for the blank lines)

5. Filtering test with grep
`grep` is the most widely used text manipulation command. 
It allows you to filter the output with specific words.
```sh
cat /etc/snort/snort.conf | grep output
#filter the snort.conf for the word "output"
```

6. Using `sed` to find and replace
`sed` stands for "stream editor". 
It allows to search for occurrences of a word or a text pattern and then perform some actions on it. 
```sh
sed s/mysql/MYSQL/g /etc/snort/snort.conf > snort2.conf
```
- `s` : Perform the substitution 
- `/mysql` : The word  to be replaced
- `/MYSQL` : The word to be replaced with
- `/g` : Replacement performed globally.
- `/etc/snort/snort.conf > snort2.conf` : Mention the file and the result will be saved as `snort2.conf` in the current working directory.

If you want to replace only the first occurrence of the term `mysql`, you would leave the trailing `g` command. 
```sh
sed s/mysql/MYSQL/ /etc/snort/snort.conf > snort2.conf
```

You can mention the which occurrence you want to replace. 
Simply place the number of the occurrence at the end of the command.
```sh
sed s/mysql/MYSQL/2 /etc/snort/snort.conf > snort2.conf
```
- `2` : Only the 2nd occurrence will be replaced
