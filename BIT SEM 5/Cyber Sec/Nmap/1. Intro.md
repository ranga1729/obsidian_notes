Nmap(Network Mapper) is an open-source network scanning and security auditing tool. 
Created by **Gordon Lyon(Fyodor)** and one of the most widely used tools. 
![[Pasted image 20251019124249.png]]
Core concept behind Nmap: Discover hosts and services on a computer network by sending specially crafted packets and analyzing their responses.

### Basic Concepts
1. Host discovery
	Find live hosts on a network using ARP, ICMP, TCP probes. 
2. Port scanning
	Determine if TCP/UDP ports are open/closed or filtered. 
	Open = services likely listening
	Filtered = Firewall/IDS may be blocking probes
3. Services & version detection
	Probe open ports to identify the service and version
4. OS detection
	Fingerprint target TCP/IP stacks to guess OS and sometimes kernel versions.
5. NSE(Nmap Scripting Engine)
	Use modular scripts(Lua) to automate checks.
