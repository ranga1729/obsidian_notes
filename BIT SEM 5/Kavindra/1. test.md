SVM, KNN, Decision Tree, Random Forest, ANN are all machine learning algorithms(ml models).
They are different approaches to learn pattern from data. 
(ANN belongs to deep learning and other are traditional machine learning methods.)

1. SVM(Support Vector Machine)
![[Pasted image 20250911100218.png]]
A supervised learning algorithm. 
Mainly used for classification(sometimes regression).

Inner working,
- Find the best boundary(hyperplane) that separates data points of different classes. 
- It maximize the margin(distance) between the boundary and the closest data points(support vectors).

Ex: Classifying emails as spam or not spam

2. KNN(K-Nearest Neighbors)
![[Pasted image 20250911100716.png]]
A supervised learning algorithm.
Used in classification or regression.

Inner working,
- When a new data point comes in, KNN looks at the K closest data points(neighbors) in the training data set. 
- It assigns the majority label(for classification) or averages their values(for regression)

3. Decision Tree
![[Pasted image 20250911101121.png]]
A supervised learning algorithm.
Used in classification or regression.

inner working,
- Splits data into branches based on questions/conditions.
- Each internal node is a decision(ex: is color = green ?)
- Each leaf node is an outcome(class or value)

In a decision, there's just a one tree like structure is being built.
Since we use multiple data to train the mode, each leaf node can contain multiple training samples that reach it. 

In a classification task, the target data will be compared from the root node to a leaf node. Since a leaf node can have multiple classes, it will choose the majority of the available classes in that particular node. 
Ex: In a leaf node, there are 10 training samples end up there. (cat:6, dog:4)
	If a new data reaches this leaf node, the prediction will be "cat".

In a regression task, instead of looking for  majority class, the calculates the average of all residing training data values that resides in that particular node. 
Ex: In a leaf node, there are 5 training data samples with house prices.(sample_1: $200, sample_2: $220,  sample_3: $210,  sample_4: $230,  sample_5: $220,)
	If the target value reaches this leaf node, the prediction will be avg = 216.

Ex: Predicting whether a person will buy a product(pizza) based on age, income, etc...

4. Random Forest
Ensemble supervised learning algorithm. 
(Ensemble supervised learning is a machine learning technique where multiple individual models(weak learners) are combined to create a single, more powerful "strong learner" with better predictive performance. Instead of relying on one model, ensembles leverage diverse perspectives and strengths from multiple models through techniques like bagging, boosting, or stacking to reduce errors, improve accuracy, increase robustness, and minimize overfitting.)

Used in classification or regression.

Inner working,
- Builds many decision tree.(called a "forest")
- Each tree gives a vote and the final output is decided by the majority(for classification) or averaging(for regression)

More robust and accurate than a single decision tree.
Ex: Credit risk prediction, medical diagnosis

5. ANN(Artificial Neural Network)
![[Pasted image 20250911101956.png]]
A deep learning algorithm.(neural network)
Can be used for classification, regression and more complex tasks(images, text, speech)

- Inspired by the human brain.  
- Consists of **layers of neurons** connected by weights. 
- Each neuron applies a mathematical function to inputs and passes it to the next layer.
- With enough layers → can model very complex relationships.

Ex: Image recognition, speech recognition, natural language processing


#### Summary
| Algorithm         | Category                  | Key Idea                            | Typical Use                            |
| ----------------- | ------------------------- | ----------------------------------- | -------------------------------------- |
| **SVM**           | Traditional ML            | Find best separating hyperplane     | Classification (spam, fraud detection) |
| **KNN**           | Traditional ML            | Classify based on nearest neighbors | Simple classification/regression       |
| **Decision Tree** | Traditional ML            | Flowchart of decisions              | Predictions with rules                 |
| **Random Forest** | Traditional ML (Ensemble) | Many decision trees combined        | More accurate prediction               |
