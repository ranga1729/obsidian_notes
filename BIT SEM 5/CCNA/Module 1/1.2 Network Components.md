#### Host Roles
- All computers connected to a network are called "Hosts" or an "end device".
- IP address is used to identify a host on a particular network.
- Some hosts are clients and others are servers.

#### Peer-to-Peer
- Its possible for a one computer to function as both a client and a server.
- when many computers function as the server and client on the network, it's called a peer-to-peer network. 
	![[Pasted image 20251208150233.png]]
- Advantages,
	Easy to setup
	Less complex
	Lower cost
	Suitable for simple tasks(ex: resource sharing)
- Disadvantages,
	No centralized admin
	Less secure
	Not scalable
	Slow performance
#### End Devices
- And end device is either the source or destination of a message transmitted over the network.
	![[Pasted image 20251208150557.png]]
#### Intermediary Devices
- Used to connect end devices to the network or to connect multiple networks to form an internetwork.
	Ex: wireless Router, LAN switch, Router, Multilayer switch, Firewall appliances
- Functions of intermediary devices,
	1. Re-generate/Re-transmit communication signals. 
	2. Maintain information about pathways in the network. 
	3. Direct data along appropriate pathways. 
	4. Classifying/prioritizing data.
	5. Permit/deny data flows based on security settings. 
#### Network Media
- Primarily use three types,
	1. Metal wires within cables : Data is encoded to electrical pulses
	2. Glass/plastic fiber within cables : Data is encoded to light pulses
	3. Wireless transmission : Data is encoded via modulation of specific frequencies of electromagnetic waves.
