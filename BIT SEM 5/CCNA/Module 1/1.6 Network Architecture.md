- Characteristics that network architectures must address,
	1. Fault Tolerance
	2. Scalability
	3. Quality of Service(QoS)
	4. Security
#### Fault Tolerance
- Networks that limits the number of affected devices during a failure are fault tolerant networks. 
- Built to allow quick recovery in a failure. 
![[Pasted image 20251209122648.png]]
- Depends on multiple paths(redundancy) between the source and destination. If one path fails, the messages are sent over a different link. 
- Implementing **"packet-switched"** network is a one way to achieve redundancy. 
	Packet switching split traffic into packets. 
	Ex: A single email broken into multiple packets. Each packet has the necessary information of the source and the destination. 
	The routers within the network switch the packets based on the condition of the network at the moment. 
- All the packets in a single message could take different paths to the same destination. Router is responsible to dynamically change the route when a link fails.

#### Quality of Service
- Quality of service is the primary mechanism of managing congestion and ensuring reliable delivery of content to all users.
- Congestion happens when the demand for bandwidth > available bandwidth. (happens when simultaneous connections are attempted across the network)
	Bandwidth : number of bits carried per second(bits per second - bps)
	When the volume of traffic is greater than the bandwidth, device will hold the packets in memory until resources becomes available to transmit them.
- The focus of QoS is to prioritize time-sensitive traffic. 
	Ex: Since the routers can manage the flow of different types of data Router can prioritize voice communication during a congestion. 
- The type of traffic matters, not the content of the traffic.

#### Network Security
- Net Admins must address two types of security,
	1. Network infrastructure security
	2. Information security
- Network infrastructure security includes,,
	1. Device physical security
	2. Prevent unauthorized access to the management software 
![[Pasted image 20251210110117.png]]
- Primary requirements of security,
	1. Confidentiality : Only the intended and authorized recipients can access and read data. 
	2. Integrity : Ensuring the information has not been altered in transmission. 
	3. Availability : Ensure reliable access to data services for users.
