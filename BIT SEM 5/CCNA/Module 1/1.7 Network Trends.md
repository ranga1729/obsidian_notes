#### 4. Cloud Computing
- Allows users to store files/backup over the internet. 
- This extends the capabilities of IT without investments in infrastructure, training new personnel or licensing and it's on-demand. 
- This is possible because of data centers.
	Large organizations built and maintain data centers and smaller organizations can lease severs and storage from the data centers.
- Cloud providers use distributed centers for security, reliability and fault tolerance. 
- Types of clouds,
	1. Public clouds : Available to the general population. Services may be free or offered on pay-per-use model. 
	2. Private clouds : Intended for specific organizations like governments. Can be setup using the organizations private network. Can be expensive to build & maintain and uses strict access security. 
	3. Hybrid clouds : A combination of a private and a public cloud where each part remains a distinct object, but both are connected using a single architecture. 
	4. Community clouds : Created for exclusive use by specific entities or organizations. Functional needs are customized for the community. Can be used by multiple organizations that have similar needs and concerns. Similar to public clouds but with set level of security, privacy, and regulatory compliances of a private cloud.
		Ex: Healthcare organization must be complaint with HIPAA policies.

- It requires a standard powerline adapter and devices can connect to the LAN whenever there is an electrical outlet.

#### 7. Wireless Broadband
Wireless Internet Service Provider : a Wireless Internet Service Provider(WISP) is an ISP that connects subscribers to a designated access point or hot spot using similar wireless technologies found in home WIFI routers.
Common in areas where DSL or cable services are not available. 
- A transmission tower may be install for the antenna. 
- A dish/a small antenna will be used by users to connect to the network.
- The main difference is the connection from the home to the ISP is wireless instead of a physical cable.
