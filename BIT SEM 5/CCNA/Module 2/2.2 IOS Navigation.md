### Primary Command Modes
As a security feature, Cisco IOS provides two command modes,
1. **User EXEC Mode(view only mode)**
	Allows only limited number of basic monitoring commands.
	Doesn't allow to change device configurations. 
	Denoted by `>` at the end of the CLI prompt. 
	![[Pasted image 20251216013022.png]]
2. **Privileged EXEC Mode**
	Allows to execute configuration commands and access to all commands/features. 
	Higher config modes(ex: global configuration mode) only allowed in this mode. 
	Denoted by a `#` at the end of the prompt. 
	![[Pasted image 20251216013037.png]]
### Configuration Mode and Sub-configuration Mode
Three types,
1. **Global Configuration Mode**
	To configure a device, the user must enter **"the global configuration mode"**.
	CLI config changes affect the device as a whole. 
	Identified by a prompt ends with `(config)#` after the device name.
	![[Pasted image 20251216013547.png]]
From the Global config mode, user can access other specific two sub-config modes which allows the configuration of a particular part/function of a device,
2. **Line configuration Mode**
	Used to configure console, SSH, Telnet or AUX access.
	![[Pasted image 20251216013907.png]]
3. **Interface Configuration Mode**
	Used to configure a switch port or router network interface.
	![[Pasted image 20251216014009.png]]

By default, the command-line prompt begin with the device name. 
Then the remainder of the prompt indicates the mode. 
Ex: 
- `Switch(config-line)#`
- `Switch(config-if)#`
----
### Navigate Between Modes
1. `enable`
	To move from 'user EXEC mode' to 'Privileged EXEC mode'. 
	![[Pasted image 20251216015419.png]]
2. `disable`
	Reverse of `enable`.
3. `configure terminal`
	To move into 'global configuration mode'
	`exit` : Get back to privileged EXEC mode and turn off the (config) mode.
	![[Pasted image 20251216015410.png]]
4. `line <management line type>`
	To move into line-config mode.
	![[Pasted image 20251216015524.png]]
5. `exit`
	To from any sub-config mode to global-config mode. 
6. `end` or `Ctrl+Z`
	To move from any sub-config mode to privilege EXEC mode.

- You can directly move between sub-config modes using `line`/`interface` commands.
	![[Pasted image 20251216020015.png]]
