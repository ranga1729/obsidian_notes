#### 8.1 Types of Malicious software
![[Pasted image 20251228201345.png]]
- A malware is program runs a computer with the intent of compromising the confidentiality, integrity or data availability.
- Malwares can be categorized into based on,
	1. How it propagates to reach the desired target. 
	2. The actions it perform once a target is reached. 

**1. Propagation based malwares**
Types,
- Virus - infect content/data
- Worms - vulnerability exploits
- Social engineering - ex: spam mails, trojans
**2. Payload based malwares**
Types,
- System corruption
- Attack agents - zombies, bots
- Information theft - keyloggers, phishing, spyware
- Stealthing - Backdoors, rootkits

- There exist some virus-creation toolkits which include a variety of propagation mechanism and payloads.
#### 8.2 Advanced Persistent Threats(APTs)
Advanced Persistent Threats (APTs) are sophisticated, long-term cyberattacks where skilled attackers (often state-sponsored) infiltrate a high-value network, remain undetected for extended periods (months to years), and methodically steal sensitive data or disrupt operations for espionage, political, or financial gain, using custom tools and complex evasion techniques.

Features,
- Careful target selection
- persistent
- stealthy
Common aims of these targets varies from theft of intellectual property or security and and infrastructure related data to the physical disruption of infrastructure.
#### 8.3 Viruses and Worms
Viruses are parasitic software that attach themselves to some existing executable content. they can infect other programs by modifying them. This modification will make copies of itself to spread more.

This software fragment can be,
- Machine code that infects applications, utility, systems programs
- Scripts that resides in words docs, Excel sheets or a PDF docs. 

Three parts of a virus,
- Infection mechanism: propagates to replicate. referred to as "the infection vector"
- Trigger: the condition/event which activates the payload. AKA a "logic bomb"
- Payload

Lifecycle phases of a virus,
1. Dormant phase: The virus is idle and eventually be activated by an event. 
	ex: a date, user installing another software
2. Propagation phase: Virus places itself into other programs/areas on the disk.
3. Triggering phase: Activate to perform a task
4. Execution phase: Perform the task.

Virus classification by target,
- Boot sector infector: Infects a master boot record(MBR) and spreads when a system is booted from the disk.
- File infector: Infects executable files
- Macro viruses: Infect files with macro or scripting code
- Multipartite virus: Infects files in multiple ways. 

Virus classification by concealment strategy,
- Encrypted virus: Uses encryption to obscure(hide) its content
- Stealth virus: A form of virus explicitly designed to hide itself from detection by anti-virus software
- Polymorphic virus: self-mutating malware that change their appearance (their "signature") using encryption/obfuscation, keeping a constant decryption engine during every time they replicate
- Metamorphic virus: advanced malware that completely rewrite their own code with each new infection, creating a new, functionally identical but structurally unique version every time, making them extremely difficult for traditional antivirus software. (doesn't use encryption)

**Macro Viruses**
- Macro viruses are malicious programs written in macro languages (like those in Microsoft Office) that infect data files (Word, Excel, PowerPoint) and spread by exploiting the software's automation features, tricking users into running them via phishing emails or infected attachments, causing data corruption, system disruption, or stealing info once activated.
- They hide within the "active content" of documents, using the legitimate-looking macro code

Features,
- Platform independent
- Infect documents, not executables.
- Easily spread as the document they resides in a shared.
- Traditional file system access controls are of limited use in preventing their spread. 

**Worms**
- A program that actively seeks out more machines to infect. 
(a standalone malware program that self-replicates and spreads across networks)
- They exploit security vulnerabilities without needing a host file or user interactions. 
- Uses network connections to spread from system to system or shared media. 
Might access remote systems like
- Email/instant messaging platforms
- file sharing
- remote execution capabilities
- remote file access
- remote login capabilities

Network address scanning method used by network worms,
- Random: infected host probes random addresses in the IP address space
- Hit-List: The attacker first compiles a long list of potential vulnerable machines. Each infected machine is provided with a portion of the list to scan
- Topological: uses information contained on an infected machine to find more hosts to scan.
- Local subnet: infected host looks for targets in its own local network

**SIR (Susceptible-Infected-Recovered) model**
Computer viruses and worms exhibit similar self-replication and propagation behavior to biological viruses.
$$
\frac{d}{dx} I(t) = \beta . I(t). S(t)
$$
- `I(t)` : number of individuals infected as of time t
- `S(t)` : number of susceptible(but not yet infected) individuals at time t
- $\beta$ : Infection rate
- size of the population(N) = I(t) + S(t)

- Initially, the number of hosts increases exponentially. 
- With time, infected hosts waste time for attacking already infected hosts, which reduces the rate of infection.
#### 8.4 System corruption
Malware will perform a task once infect the system,
- Destroying data
- displaying unwanted messages or content
- Inflicting physical damage. 

- Ransomware - a type of malware that encrypts the user's data and demand payment in order to access the key.
#### 8.5 Attack Agents
- Attack agents - subvert the computational and network resources of the infected system for use by the attacker. 
	Those systems are called bots, zombies or drones.
	They secretly takes over another Internet-attached computer and then uses that computer to launch or manage attacks that are difficult to trace to the bot's creator.
- A collections of bot are called "botnets", can act in a coordinated attacks. 
Ex:
- DDOS
- spamming
- sniffing traffic
- keylogging
- spreading new malware
- Installing add-ons to browsers
- Attacking IRC chat networks
- Manipulating online polls
- Crypto mining

- Worms propagates itself and activates itself, whereas a bot is controlled by some form of command-and-control (C&C) server network.
- The bots can contact the C&C through various means, such as HTTP protocol and peer-to-peer communication protocols.
#### Keyloggers, Phishing and Spyware
- Some malwares gather data stored in the infected systems. 
	ex: user's login and passwords credentials
- Keyloggers captures keystrokes on the infected machine
- Spyware monitors a wide range of activity on the system. 
	browsing activities, redirecting to malicious web pages, dynamically modifying data exchanged between the browser and certain Web sites
- Phishing - user logs into a fake Website controlled by the attacker, which mimics the login page of some banking, gaming, or similar site. then attacker gets user credentials.
- Spear-phishing :  a phishing attack but the victims are well researched by the attacker and each email is crafted specifically for the victim.
	particularly used in industrial and other forms of espionage by well-resourced organizations
#### Stealthing : Backdoors and Rootkits
- Stealthing are techniques used by malwares to hide itself in the infected system. 
- Backdoor - aka trapdoor. a secret entry point into a program that allows someone who is aware of the backdoor to gain access without going through the usual security access procedures
- Programmers use legitimate backdoor for testing purposes.(maintenance hooks)
- Rootkit - a set of programs installed on a system to maintain covert access to that system with administrator (or root) 3 privileges, while hiding evidence of its presence to the greatest extent possible.
	This provides access to all the functions and services of the operating system

- Rootkit features,
	- Persistence
	- Has no persistent code and therefore cannot survive a reboot
	- User mode: Intercepts calls to APIs (application program interfaces) and modifies returned results.
	- Kernel mode: Can intercept calls to native APIs in kernel mode
	- Installs a lightweight virtual machine monitor, and then runs the OS above it
	- External mode: The malware is located outside the normal operation mode of the targeted system. ex: BIOS.
