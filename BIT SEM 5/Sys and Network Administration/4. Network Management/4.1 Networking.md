### Firewall and NAT
#### 1. Linux iptables
A command line utility used to configure the linux kernel's built-in firewall. 
It acts as a gatekeeper, inspecting incoming and outgoing network traffic and deciding whether to allow it, block it or forward it based on the rules we define. 
Key components,
1. Tables
	Tables categorize rules based on the type of decision being made. 
	Common tables are,
	- Filter table: (default and most used) decide whether a packer should be allowed to reach its destination or be blocked. 
	- NAT(Network Address Translation): Used to route packets to different networks or modify the source/destination IP. 
	- Mangle table: Used for specialized packet alteration.
2. Chains
	Where rules get applied to network packets. 
	Chains in filter table,
	- INPUT: for packets destined to my local machine
	- OUTPUT: for packets generated by my machine and going-out.
	- FORWARD: for packets that are just passing my machine(ex: if you machine acts as a router.)
3. Target
	Once a packet matches a rule, the target decides what happens next,
	- ACCEPT: Let the packet through.
	- DROP: Ignore the packet completely(sender gets no response)
	- REJECT: block the packet(send gets a response)
	- LOG: record the packet info in the system log(before dropping or accepting it)
Ex:
![[Pasted image 20251222061328.png]]
```shell
iptables -A INPUT -p tcp --dport 80 -j DROP
```
- `-A INPUT` : Append this rule to the INPUT chain. 
- `-p tcp` : Look for the TCP protocol.
- `--dport 80` : Target the destination port 80
- `-j DROP` : Tell the system to DROP the packet. 

- A linux firewall is usually implemented as a series of iptables. 
#### 2. Linux NAT(Network Address Translation)
![[Pasted image 20251222061627.png]]
NAT allows multiple devices on a private network to share a single public IP for internet access. This conserves addresses and boosting security, typically by configuring a linux box with two network interfaces(internal/external) using `iptables`(or `firewalld`) for IP forwarding and masquerade, effectively turning the linux machine into a router. 
iptables implement NAT as a packet filtering as well.

How it works,
- Dual interface - **The server needs one network card (e.g., `eth0`) for the internal LAN and another (e.g., `eth1`) for the external internet connection.**
- IP Forwarding - The Linux kernel must be told to forward packets between interfaces.
- Address Translation - When a device on the internal network sends traffic out, the `iptables` rule changes the source IP from the private address to the Linux server's public IP (Masquerading).
- Reply handling - When return traffic comes back, the server translates the destination IP back to the original internal device's private IP.
