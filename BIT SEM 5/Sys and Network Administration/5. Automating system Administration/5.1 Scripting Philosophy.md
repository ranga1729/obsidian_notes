**Scripting** is the practice of writing a sequence of commands in a **text file** so the computer can execute them automatically, instead of typing each command manually.

In Linux, scripts are most commonly written using **shell scripting** (usually **Bash**).
![[Pasted image 20251220212834.png]]
Shell programs in linux,
- Bourne shell, sh
- Almquist shell, ash
- Bourne-again shell, bash
- Korn shell, ksh
- S shell, csh

A shell script can consist of nothing but a series of command lines.

Ex:
1. Create a script file
```bash
nano myscript.sh
```
2. Add the shebang line
	This tells Linux **which interpreter** should run the script.
```sh
#!/bin/bash
```
3. Write commands
```bash
#!/bin/bash
echo "Hello, World!"
date
```
4. Make the script executable
```bash
chmod +x myscript.sh
```
5. Run the script
```sh
./myscript.sh
```

### Syntax
1. Variables
```bash
name ="John" 
echo "Hello, $name"
```
2. Read user inputs
```bash
echo "Enter your name: "
read name
```
OR
```bash
read -p "Enter your name: " name
```

3. Conditional statements
```sh
if [ $age -ge 18 ]; then
	echo "Adult"
else
	echo "Minor"
fi
```
- `-ge` : greater than or equal 
- `-gt` : greater than

4. for loop
```sh
for val in {1..5}
do
	echo $val
done
```

5. while loop
```bash
x = 1
while [ $x -le 10 ]
do
	echo $x
	((x++))
done
```

6. arithmetic
```bash
a = 10
b = $((20))

c = $a + $b
d = $((a+b))

echo "$a + $b = $c \t(plus sign as string literal)"
echo "$a + $b = $d \t(plus sign as arithmetic addition)"
```

#### Regular Expressions
Standardized patterns that parse and manipulate text. 
Ex:
	Comparison operator: `=~`
	Any single digit: `[0-9]`
	Any capital letter: `[A-Z]`
	Any sequence of capital letters: `[A-Z]+`
	Beginning of a string: `^`
	End of a string: `^`
Ex:
```bash
#!/bin/bash

echo "Enter a digit: "
read digit

if [[ $digit =~ [0-9] ]]; then
	echo "$digit is a digit"
else 
	echo "$digit is not a digit"
fi
```
