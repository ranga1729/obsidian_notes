A System Administrator(SysAdmin) is the person responsible for managing, maintaining and ensuring reliable operation of an organization's IT systems, servers. networks and other infrastructure. 

Essential duties of a SysAdmin,
- Controlling access
- Adding hardware
- Automating tasks
- Overseeing backups
- Installing and upgrading software
- Monitoring
- Troubleshooting
- Maintain local documentation
- Vigilantly monitoring security
- Tuning performance
- Developing site policies
- Working with vendors
### Linux Distributions

All distributions share the same kernel lineage but the format, type, focus, support, popularity and number of packages differ.

#### Man Pages & Other Documentations
The manual pages(man pages) can be read with the `man` command.
```shell
man ls 
#show the manual page of the ls command
```
![[Pasted image 20250827154828.png]]

Sections of a man page,
- User-level commands and applications
- System calls and kernel error codes 
- Library calls 
- Device drivers and network protocols 
- Standard file formats 
- Games and demonstrations 
- Miscellaneous files and documents 
- System administration commands 
- Obscure kernel specs and interfaces

Other on-line documentations,
- System-specific guides
- Package specific docs
- Books
- RFC publications

#### Ways to find and install software
Modern OS divide their content into packages that can be independently of one another. 
Most software is developed by independent groups that release the software in the form of source code. 
Package repositories then pick up the source code, compile it and package the resulting binaries.

- `which` command can be used to check whether a package is already available in the system. 
```sh
which gedit
/usr/bin/gedit

#gedit is the ubuntu text editor
#it returns the pathname if exists
```
![[Pasted image 20250827163126.png]]

- Installing software package 
1. using a package manager(apt or yum)
```sh
sudo apt install gedit
sudo yum install gedit
```
2. Download the source code, compile it and install
3. Execute a script which download and install the application
