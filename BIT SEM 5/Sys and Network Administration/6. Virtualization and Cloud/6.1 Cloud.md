The practice of leasing computer resources from a pool of shared capacity.
Users of cloud services provision resources on demand and pay a metered rate for whatever they consume.

Reason to transit from on-prem to clous,
- Cloud providers have advanced infrastructure 
- Design custom server chassis to maximize energy efficiency and minimize maintenance
- Automate to allow rapid expansion
- Reduce the likelihood of human errors. 
- Uses purpose-built network infrastructure with custom hardware and software
Factors influenced cloud,
- Cost
- Past exp
- Compatibility with existing technology
- Security, compliance requirements
- Internal politics

Cloud services types,
- Infrastructure-as-a-service (IaaS)
- Platform-as-a-service (PaaS)
- Software-as-a-service (SaaS)

- Automation

#### Virtualization
- Hypervisor is a software/ hardware that mediates between virtual machines (VMs) and the underlying hardware on which they run.
- Hypervisors are responsible for sharing system resources among the guest operating systems, which are isolated from one another and which access the hardware exclusively through the hypervisor.
- Guest operating systems are independent.

Types of virtualization,
- Full virtualization
- Paravirtualization
- Hardware-assisted virtualization
- Para-virtualized drivers

- Live migration 
	Virtual machines can move between hypervisors running on different physical hardware in real time
- Virtual machine images
	Virtual servers are created from images, which are templates of configured operating systems that a hypervisor can load and execute
- Containerization
	a different approach to isolation that does not use a hypervisor.

#### Xen
![[Pasted image 20251220233725.png]]
- open source project from the linux foundation
- Paravirtualization
- used to run AWS clouds and IBM SoftLayers
- Xen is a bare-metal hypervisor that runs directly on the physical hardware.
#### KVM
![[Pasted image 20251220233804.png]]
- kernel based
- Full virtualization platform
- Under KVM, the Linux kernel itself serves as the hypervisor.
- Memory management and scheduling are handled through the host’s kernel, and guest machines are normal Linux processes.
