1. Regular files
	Most common type, contains user data, program code, images, binaries, etc. 
2. Directories
	Special files that store lists of filenames and their corresponding **inode numbers**. 
Files are indicated by `-` and directories are by `d` in `ls -l` command.
![[Pasted image 20250917123040.png]]

> [!NOTE] Inode
> **Inode** is a data structure in linux containing metadata about the file or directory. 
> An **inode number** is a unique integer assigned to each file and directory within a specific filesystem. 
> A directory is a table mapping `filename --> inodes`.

3. Character Device Files
	Represent devices that handles data/one character at a time. (unbuffered/IO).
	Ex: keyboards, mice, serial ports
	Found in `/dev`
	Represented by `c` in `ls -l` command.
![[Pasted image 20250917133200.png]]

4. Block device files
	Represent devices that transfer data in blocks. 
	Ex: Hard disks, SSDs, USB drives
	Found in `/dev`.
	Represented by `b` in `ls -l` command.
![[Pasted image 20250917133407.png]]

5. Local domain sockets
	Used for **Inter-Process Communication(IPC)** between processes on the same machine. 
	Appears as special filesystem objects. 
	Ex: `X11`, `systemd`, Docker use Unix domain sockets
	Represented by `s` in `ls -l` command. 
```sh
srwxr-xr-x 1 user user 0 Sep 17 10:00 /tmp/mysocket
```

6. Named Pipes
	Special files used for **one-way communication** between processes(like a pipe `|`, but persistent in the filesystem)
	One process writes another reads. 
	Represented by `p` in `ls -l` command.
```sh
prw-r--r-- 1 user group 0 Sep 17 10:00 mypipe
```

7. Hard Links
	A directory entry that refers to the same inode as another file.
	Both names point to the same data on disk. 
	If you delete one, the other still exists until all links are removed. 
	Hard links can be created using `ln` command.
```sh
ln existingFile newLinkName
```
![[Pasted image 20250917134808.png]](both `test` and `test2` opens the same file because they are two different directory entries refers to the same inode.)

8. Symbolic Links(Soft Links)
	Special files that point to another pathname. (like shortcuts in windows)
	If the target is deleted, the symlink becomes "broken".
	Represented by `l` in `ls -l`
```sh
lrwxrwxrwx 1 user user 12 Sep 17 10:00 mylink -> /etc/hosts
```
Soft links can be created with the same `ln` command with `-s` attribute.
```sh
ln -s target linkName
```
