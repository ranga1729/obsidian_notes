- `/etc/passwd` : Stores user account information
- `/etc/shadow` : Stores password and expiration data
- `/etc/group` : Stores group information

A group is a way to organize users so they can share permissions. The `/etc/group` file defines all groups on a linux system. 

Ex:

Each line in this file describes one group,

| Filed | Name       | Description                                                                             |
| ----- | ---------- | --------------------------------------------------------------------------------------- |
| 1     | group name | The name of the group.                                                                  |
| 2     | password   | Optional group password                                                                 |
| 3     | GID        | Group ID                                                                                |
| 4     | user list  | A comma-separated lists of users who are members of this group(beside the primary user) |
Ex:
```sh
root:x:0:
sudo:x:27:john,emma
developers:x:1001:john,alice
john:x:1002:
```
- The `root` group has GID 0 and no extra members
- `john` and `emma` can use `sudo` privileges.
- `john` and `alice` are in the `developers` group.

Every user typically has their own private group with the same name and GID as their UID. 

From the perspective of a user, group are in two categories,
1. Primary group : The default group of a user. Defined in the `/etc/passwd`(filed 4, GID)
2. Secondary groups : They grant extra permission for shared resources. Listed in `/etc/group`(filed 4, user list). 
Ex: 
In `/etc/passwd` file, 
```sh
john:x:1001:1001:John Doe:/home/john:/bin/bash
```
- The primary group of john is GID = 1001

In `/etc/group` file,
```sh
root:x:0:
sudo:x:27:john,emma
developers:x:1001:john,alice
john:x:1002:
```
- Secondary groups of john : sudo, developers
