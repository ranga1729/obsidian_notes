##### 1. Separate ecosystems
Instead of having a single "root" user controlling everything, modern systems try to isolate resources into separate domains or ecosystems. 
Ex: Containers(docker, LXC), Virtual machines

Benefits,
- If one ecosystem is compromised, the attacker cannot easily affect the others. 
##### 2. Mandatory Access Control(MAC)
A stricter security model compared to the traditional **discretionary model**. 
In **DAC(Discretionary Access Control)**, the owner of a file decides who can access it(via `chmod`, `chown`)
In **MAC(Mandatory Access Control)**, the system enforces security policies that even root cannot easily bypass. 

Ex: 
- SELinux(Security Enhanced Linux): SELinux (Security-Enhanced Linux) is a security module built into the Linux kernel that implements Mandatory Access Controls (MAC)
	![[Pasted image 20250903184000.png]]
- AppArmor : AppArmor is a Linux security module that restricts individual applications by using per-program security profiles to define their capabilities and access to system resources.
	![[Pasted image 20250903183921.png]]
These enforces predefined rules about which processes can access which files, sockets or system calls. 

Benefits,
- Helps prevent privilege escalation 
- Limits what compromised applications can do
##### 3. Role-Based Access Control(RBAC)
![[Pasted image 20250903184159.png]]
Instead of granting permission directly to users, permissions are grouped into roles and users are assigned to roles. 

Ex: 
	`DatabaseAdmin` : Can manage database, but not system files
	`WebServerManager` : Can restart web servers, but not the database.

Usages,
- Kubernetes RBAC
- Enterprise Identity Management Systems(like Active Directory)
