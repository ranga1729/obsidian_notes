The local(or cloud) environment has to be properly designed.

Considerations,
- Non-administrators should not have root privileges. Instead give them only the permission they need.(Principle of least privilege)
- The IT setup should help users do their jobs easily, not make it harder with over-restrictions or confusing workflows. 
- If a user makes mistakes or try to bypass rules, treat them as learning opportunities. 
- Keep customers needs in mind when setting up or configuring systems. 
- Keep your local documentation up to date and easily accessible. 
- If you have to manage many devices with different configs, split them into manageable groups. (Ex: group machines by department, OS type, usage)
- Don't roll out updates to everyone at once.
	Test updates on a small group, fix issues, then roll out to bigger groups.
	(prevent system wide failures)
- Don't allow too many different versions of software to exist across your organization. Set a **maximum number of supported releases**. (ex: only the latest updated version + previous version)
- Always test configurations and updates before rolling them out widely. Test your own configs as well as vendor updates.
