#### Low-level package managers
Work directly with package files(Ex: `.deb` for Debain/Ubuntu, `.rpm` for Red Hat/Fedora)
They can install, remove, query a single package.
But they,
- do not automatically fetch software from online repos.
- do not resolve dependencies automatically. 
Ex: 
- `dpkg`, `rpm`
#### High-level package managers
Built on top of low-level managers.
Handles everything automatically including,
- Fetch software from online repos(not just local files)
- resolve dependencies
- Manage updates and upgrades
- Provide search functionality
Ex: 
	`apt`/`apt-get` (for Debain/Ubuntu, built on top of `dpkg`)
	`yum`/`dnf` (Red Hat/Fedora, built on top of `rpm`)

*****
#### 1. APT (Advanced Package Tool) - Debain/Ubuntu
APT is the high-level package manager for debain-based system. 
It uses `dpkg` underneath but adds intelligence.

Common commands,
```sh
sudo apt update
sudo apt install firefox
sudo apt remove firefox
sudo apt upgrade
apt search vlc
apt show vlc #show package details
```
#### 2. YUM (Yellowdog Updater, Modified) - Red Hat/Fedora
YUM was the high-level package manager for Red-Hat based distros. In modern Fedora/CentOS/RHEL, its has been mostly replaced by DNF(Dandified YUM) which is faster and more reliable.

Common commands,
```sh
sudo yum update
sudo yum install firefox
sudo yum remove firefox
yum search vlc
yum info vlc #show package details
```
