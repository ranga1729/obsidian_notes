Two general approaches to add a new use,
1. Manual(low level) - editing system files directly
	Edit `/etc/passwd`, `/etc/shadow`, `/etc/group` files. 
2. Command-based(high level)
	Using tools like `useradd`, `adduser`, `usermod`. 
	The recommended way.

##### What happens when you add a user,
Regardless of the method, linux perform these actions,
1. Edit `/etc/passwd` : Add user info
2. Edit `/etc/shadow` : Add hashed password
3. Edit `/etc/group` : Create or assign user to a group
4. Set a password, store it securely in `/etc/shadow` file. 
5. Create a home directory (ex: `/home/john`)
6. Set permissions : owner=user, group=user's group
7. Copy default files from `/etc/skel` into the user's home directory
8. set shell and roles : define what shell user uses and what commands they can run

------
#### 1. Manual Method
Involves editing core files using text editors. 
Possibility of making typos is high. 
Always backup main user management files(`passwd`, `shadow`, `group`) before changes. 
Steps,
1. Edit the `/etc/passwd` file
```sh
sudo nano /etc/passwd
```
Add new user data,
```sh
john:x:1003:1003:John Doe:/home/john:/bin/bash
```
2. Edit the `/etc/shadow` file
```sh
sudo nano /etc/shadow
```
Add the line,
```sh
john:!:19600:0:99999:7:::
```
	! means account locked until a password is set
3. Edit the `/etc/group` file
```sh
sudo nano /ect/group
```
Add the line,
```sh
john:x:1003
```
4. Create the home directory
```sh
sudo mkdir /home/john
```
5. Set ownership and permission on the newly created home directory
```sh
sudo chown john:john /home/john
sudo chmod 700 /home/john
```
6. Copy default configuration files
```sh
sudo cp -r /etc/skel/. /home/john/
```
7. Set a password
```sh
sudo passwd john
```


-----
#### 2. Script/Command-based method
These commands automate all the manual steps above. 
1. `useradd` - a low-level utility to create a new user account
Ex:
```sh
sudo useradd -m -s /bin/bash -c "John Doe" john
```
- `-m` : Creates home directory
- `-s /bin/bash` : sets login shell
- `-c "John Doe"` : Comment/description(goes in GECOS filed)
- `john` : username
Then set a password using `passwd` command.
```sh
sudo passwd john
```

This modifies `/etc/passwd`, `/etc/shadow`, `/etc/group` and creates a home directory automatically.

2. `adduser`
A Perl script that calls `useradd` internally and automate all steps including the password setting interactively. 
```sh
sudo adduser john
```
```
Adding user `john' ...
Enter new UNIX password:
Retype new UNIX password:
Full Name [ ]: John Doe
Room Number [ ]:
Work Phone [ ]:
Home Phone [ ]:
```

3. `usermod`
Modify an existing  user account. 

Ex:
- Add user to a secondary group
```sh
sudo usermod -aG sudo john
```
	-aG : append to group
- Change user's login shell
```sh
sudo usermod -s /bin/zsh john
```
- Change home directory
```sh
sudo usermod -d /home/newjohn john
```

4. `chsh` (Change shell)
Used to change a user's login shell.
```sh
sudo chsh -s /bin/zsh john
```

5. `chpasswd` (Change password)
Quickly set passwords for multiple users from a script.
```sh
echo "john:password123" | sudo chpasswd
```
