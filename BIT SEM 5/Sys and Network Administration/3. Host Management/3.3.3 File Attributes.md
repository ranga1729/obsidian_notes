Each file has metadata(stored in its inode) that describes,
- File type(regular, directory, device, etc,...)
- Size
- Timestamp(access, modification, change)
- Owner(user ID, group ID)
- Permissions(r, w, x)
- Special bits(`setuid`, `setgid`, sticky bit)

We can see them using,
```sh
ls -l #OR
stat filename
```

#### Permission Bits
Permission bits are divided into three sets : **owner**, **group**, **others**
- **r**(read) : view the file/list directory content
- **w**(write) : modify file/ add or remove files from directory
- **x**(execute) : run file as a program/enter directory
Ex: 
```sh
-rwxr-xr-- 1 user group 123 Sep 17 10:00 script.sh
```
- Owner: `rwx`
- Group: `r-x`
- Others: `r--`
#### Special Permission Bits
Beyond the normal `rwx` bits, there are three special bits, 
1. setuid
2. setgid
3. Sticky bit

##### 1. Setuid(Set User ID on Execution)
Applies to executables. 
When set, the program runs with the permissions of the file's owner, not the user who ran it. 
Ex: `passwd` command is owned by root but need to allows normal users to update their password.
```sh
-rwsr-xr-x 1 root root 54256 Sep 17 10:00 /usr/bin/passwd
```
- Notice the `s` in owner's execute place.
If this `s` is,
- Lowercase : executable bit it set
- Uppercase : executable bit is not set(invalid but still marked).
![[Pasted image 20250917153116.png]]
##### 2. Setgid(Set Group ID on Execution/directories)
- On executable: Program runs with the group privileges of the files. 
- On directories: Files created inside inherit the group ownership of the directory. (not the creating user's primary group)
Ex:
```sh
drwxr-sr-x 2 user devs 4096 Sep 17 10:00 shared_dir
```
- Notice the `s` in the groups permission bit. (`r-s`)
- All new files inside `shared_dir` will have group `devs`.
##### 3. Sticky Bit
Works on directories only. Means that, only the owner of a file(or root) can delete/rename it, even it others have write permission to the directory. 
Used in shared directories like `/tmp`.
Ex: 
```sh
drwxrwxrwt 10 root root 4096 Sep 17 10:00 /tmp
```
- Notice the `t` at the end. 
- without sticky bit, any user with write permission could delete another user's file form `/tmp`

#### Octal Representation
Permission are often written as octal numbers. 
- **r** = 4
- **w** = 2
- **x** = 1

Ex: 
`rwxr-xr--` = 754
- Owner : `rwx` = 7
- Group : `r-x` = 5
- Others: `r--` = 4

Special bits are represented as an **extra leading digit**,
- `4XXX`= setuid
- `2XXX` = setgid
- `1XXX` = sticky
Ex: `chmod 4754` = setuid + `rwxr-xr--`

#### Commands to change permissions
1. `chmod` - Change file permissions
Modify read(`r`), write(`w`) and execute(`x`) permissions of files and directories. 

Syntax
```sh
chmod [options] mode filename
```

Two ways to specify mode,
- Symbolic mode
```sh
chmod u+x file.txt #add execute permission for owner(user)
chmod g-w file.txt #remove write permission from group
chmod o=r file.txt #set read-only for others
chmod a+r file.txt #give read to everyone
```
- Octal mode
	r = 4, w = 2, x = 1
	Combine values -> `rwx = 7`, `rw- = 6`, ...
```sh
chmod 644 file.txt # -rw-r--r--
chmod 755 file.txt # -rwxr-xr-x
chmod 700 file.txt # -rwx------
```

2. `chown` - Change file owner
Change the owner(and optionally the group) of a file.

Syntax,
```sh
chown [owner][:group] file
```

Ex: 
```sh
chown alice file.txt #chnage owner to alice
chown alice:dev file.txt #change owner to alice and group to dev
chown :dev file.txt #change only the group
```
**Only the root or a user with privileges can change ownership**.

3. `chgrp` - Change Group Ownership
Change just the group of a file. (without touching owner)

Syntax,
```sh
chgrp group file
```

Ex:
```sh
chgrp developers projects/ #assign group "developers" to project dir
```
**`chgrp` is a subset of `chown :group`**.

3. `umask` - Default permission mask
Sets the default permissions for newly created files/directories. 
Works by subtracting permissions from the maximum allowed,
- For file = `666` (`rw-rw-rw-`)
- For directories = `777` (`rwxrwxrwx`)

Syntax,
```sh
umask [mask]
```

Ex:
```sh
umask 022
```
- Files: `666 - 022` = `-rw-r--r--`
- Directories: `777 - 022` = `drwxr-xr-x`

To check current,
```sh
umask
```
