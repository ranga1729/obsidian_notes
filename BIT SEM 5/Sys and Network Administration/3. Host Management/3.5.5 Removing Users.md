When deleting a user, we have to check the following,
- Remove the user from any local user database or phone lists
- Remove the user from mail aliases databases or add a forwarding address.
- Remove the user's crontab file and pending jobs. 
- Kill any user processes that still running. 
- Remove the user from `passwd, group, shadow` files. 
- Remove the user's home directory.
- Remove the user mail spool.
- Clean up entries on shared calendars, room reservation systems, etc.
- Delete or transfer ownership of any mailing lists un by the deleted user. 

1. `userdel` 
The standard command to delete user accounts in linux. 
```sh
sudo userdel john
```
This removes entries from,
- `/etc/passwd`
- `/etc/shadow`
- `/etc/group`
But the home directory `/home/john` remains.

To delete a user with it's home directory.
```sh
sudo userdel -r john
```
	-r : removes home direcotry(/home/john) of and mail spool(/var/mail/john)

If there's any process is ongoing under the user name you want to delete, the system will stop deleting the user. 
```
userdel: user john is currently used by process 1234
```

To handle this,
```sh
sudo pkill -u john
sudo userdel -r john
```

Additionally, force delete user,
```sh
sudo userdel -f -r john
```
