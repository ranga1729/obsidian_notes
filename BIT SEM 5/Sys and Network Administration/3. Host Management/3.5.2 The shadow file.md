The `/etc/shadow` file stores the encrypted(hashed) passwords and account security information for all system users. 
It was introduced to improve security, because `/etc/passwd` file in readable by all users and storing password hashes there is unsafe.  

So modern systems split the data,
- `/etc/passwd` : public user info
- `/etc/shadow` : private password info(restricted access)

Only the root user or processes with special privileges can read this file. 
Permissions are typicall,
```sh
-rw-r----- 1 root shadow /etc/shadow
```
- Owner : root(read/write)
- Group : shadow(read)
- Other : no access

Each line in this file corresponds to one user account and contains 9 fields separated by colons,

| Filed | Name               | Description                                                  |
| ----- | ------------------ | ------------------------------------------------------------ |
| 1     | username           | The login name of the user(must match `/etc/passwd`)         |
| 2     | encrypted password | The hashed password(or a special value if login is disabled) |
| 3     | last change        | Days since Jan, 1970 when the password was last changed.     |
| 4     | min                | Minimum days before password can be changed again.           |
| 5     | max                | Maximum days before password must be chnaged.                |
| 6     | warn               | Days before expiration to warn the user.                     |
| 7     | inactive           | Days after password expires before the account is disabled.  |
| 8     | expire             | Absolute day(since Jan 1, 1970) when the account expires.    |
| 9     | reserved           | Unused, reserved for future use.                             |

Ex: 
```sh
john:$6$HJasR32x$KDeuEoZlF4ZrWmVY1hX7NbpY4zFuxbXQ8yxdO9hByl3kWf5eohSkl1Y9n.:19580:0:99999:7:::
```
- `john` : username
- `$6$HJasR32x$KDeuEoZl...` : encrypted password (`$6$` means the password is hashed using `SHA-512`)
- `19580` : password last changed 19580 days after Jan 1, 1970
- `0` : No minimum time between password changes.
- `99999` : password never expires
- `7` : warn user 7 days before expiry.
- Remaining fields empty. 

Special values in Password field,
- `*` or `!` : Account disabled(no login)
- Empty(`""`) : No password required(rare, insecure)
- `$id$salt$hash` : Normal hashed password format.
