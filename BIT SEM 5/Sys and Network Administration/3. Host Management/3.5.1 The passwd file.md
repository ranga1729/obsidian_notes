The `/etc/passwd` file in Linux stores information about all user accounts on the system. It acts as a user database. 

Each line in the file represents one user account and contains details,

| Filed | Name           | Description                                                                                       |
| ----- | -------------- | ------------------------------------------------------------------------------------------------- |
| 1     | username       | The login name(ex: root, john)                                                                    |
| 2     | password       | Traditionally stores the encrypted password. Now the real password is stored in the `/etc/shadow` |
| 3     | UID            | User ID, a unique number identifying the user. (ex: 0 for root. 1000+ for normal users)           |
| 4     | GID            | Group ID, the user's primary group defined in `/etc/group`                                        |
| 5     | comment(GECOS) | A text field that usually stores the user's full name or other info.                              |
| 6     | home directory | The path to user's home directory.                                                                |
| 7     | login shell    | The program that runs after login.                                                                |
Ex: 
```sh
john:x:1001:1001:John Doe:/home/john:/bin/bash
```
- `john` : username
- `x` : password stored in `/etc./shadow`
- `1001` : user ID
- `1001` : primary group ID
- `John Doe` : full name
- `/home/john` : home directory
- `/bin/bash` : default shell

> [!NOTE] Security Note
> In older Unix systems, `/etc/passwd` contained actual password hashes.
> Now passwords are stored in `/etc/shadow`, which is only readable by root for better security.


 The `/etc/passwd` file must be remain readable by all, because many system programs need access to user information
	 ex: login names and home directory
