A user can be lock out mainly in two ways,
1. Password lock
2. Full account lock
#### 1. Password Lock
This lock only the user's password, not the whole account. 
```sh
sudo passwd -l username
```

This will prefix the encrypted password filed in `/etc/shadow` with two exclamation marks(`!!`). 
Ex: 
```
Before:
username:$6$abc123...:19745:0:99999:7:::

After:
username:!!$6$abc123...:19745:0:99999:7:::
```
This prevents password-based login(since no password hash will match).
But the user account is still active. Therefore still they can,
- login via SSH key authentication
- run cron jobs, background services.

To check the status,
```sh
sudo passwd -S username
```

#### 2. Full Account Lock
This command locks the entire account, not just the password. 
```sh
sudo usermod -L username
```
This prefix the user's password in `/etc/shadow` with a single `!`.

Ex:
```
Before:
username:$6$abc123...:19745:0:99999:7:::

After:
username:!$6$abc123...:19745:0:99999:7:::
```
The `!` makes the entire account temporarily disabled. 
User cannot log in by any authentication method. 
Background processes or cron jobs owned by the user are also affected.
