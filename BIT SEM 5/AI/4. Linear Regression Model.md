Linear regression model is a supervised learning algorithm(Regression category) used for predicting a continuous numerical values based on one or more input features.

A data set used to train the model is called the "Training set."
In supervised learning, the training data set is consist of,
1. Input called the "input variable" or "feature". Denoted by lowercase "**x**". 
2. Output(correct answers) is called the "output variable" or the "target variable", denoted by lowercase "**y**".

In the above example,
	x : size in square feet
	y : Price in $1000
Each row represent a different "training example".
A single training example = $(x, y)$
To denote the $i^{th}$ training example = $(x^{(i)}, y^{(i)})$ 

The total number of training sample is denoted by "**m**". 

****
To train the mode, we feed both the input variables and output targets to the learning algorithm. Then out algorithm will produce a function usually call the "hypothesis"

X is the input feature and $\widehat{Y}$ is used for an estimate or a predictions.
