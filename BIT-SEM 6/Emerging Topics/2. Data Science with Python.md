Data is a collection of information. 
Types of data,
1. Unstructured 
2. Structured 

#### Data Science
Interdisciplinary field that uses scientific methods, processes, algorithms and systems to extract knowledge and insights from structured and unstructured data.
Involves various fields like,
- Statistics
- Machine Learning
- Computer Science
- Domain knowledge

Gola of data science: gain insights and make data driven decisions to solve complex problems in various industries, such as healthcare, finance, and retail

Data science is about finding patterns in data, through analysis and make future predictions.
Companies use data science for,
1. Better decisions
2. Predictive analysis
3. Pattern discovery

Industries Data Science is used for,
1. Healthcare: analyze patient data to improve diagnosis and treatment
2. Finance: detect fraud, predict stock prices, and manage financial risks
3. Retail: optimize pricing, identify customer buying patterns, and improve marketing strategies
4. Manufacturing: optimize production processes, improve supply chain efficiency and monitor equipment performance
5. Media and entertainment: analyze audience data and improve content recommendations
6. Marketing and Advertising: analyze customer data, improve targeting and personalization, and optimize ROI
7. Government: improve public service delivery and in decision making for policies
8. Transportation: optimize routes, predict maintenance needs, and improve overall efficiency
9. Energy: optimize energy consumption, predict equipment failures and improve overall performance
10. Sports: analyze player performance and game data to gain insights and improve performance

Data scientist requires,
1. Machine Learning
2. Statistics
3. Programming(Python or R)
4. Mathematics
5. Databases

Data scientist must organize data in a standard format before find any patterns within the data. 

Typical process of data scientist follows,
1. Define the problem
	Understand the problem
	Define the objectives and goals for the project.
2. Collecting and clean the data
	Accessing different data sources
	Merging and transforming the data
	Removing any errors or inconsistencies
3. Explore the data
	Explore the data to gain insights and understand its characteristics
	Techniques: visualization, descriptive statistics, correlation analysis
4. Model the data
	Use techniques from statistics and machine learning to build models that can be used to make predictions and reveal relationships between different variables. 
5. Evaluating the model
	Evaluate the performance of the models using techniques such as cross-validation
6. Communicating the results
	Communicate the results to the relevant stakeholders
7. Deployment
	Deploy the model to the production, automate decision making.
8. Monitoring and maintenance

#### Data Engineering
The process of designing, building, maintaining, and troubleshooting the infrastructure and systems that support the collection, storage, and processing of data. 

Data engineers work closely with data scientists and analysts to make sure that the data is accurate, reliable, and available for analysis and decision-making.
