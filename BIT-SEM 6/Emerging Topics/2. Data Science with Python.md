#### Data Science
Interdisciplinary field that uses scientific methods, processes, algorithms and systems to extract knowledge and insights from structured and unstructured data.
Involves various fields like,
- Statistics
- Machine Learning
- Computer Science
- Domain knowledge

Gola of data science: gain insights and make data driven decisions to solve complex problems in various industries, such as healthcare, finance, and retail

Data science is about finding patterns in data, through analysis and make future predictions.
Companies use data science for,
1. Better decisions
2. Predictive analysis
3. Pattern discovery

Industries Data Science is used for,
1. Healthcare: analyze patient data to improve diagnosis and treatment
2. Finance: detect fraud, predict stock prices, and manage financial risks
3. Retail: optimize pricing, identify customer buying patterns, and improve marketing strategies
4. Manufacturing: optimize production processes, improve supply chain efficiency and monitor equipment performance
5. Media and entertainment: analyze audience data and improve content recommendations
6. Marketing and Advertising: analyze customer data, improve targeting and personalization, and optimize ROI

#### Data Engineering
The process of designing, building, maintaining, and troubleshooting the infrastructure and systems that support the collection, storage, and processing of data. 

Data engineers work closely with data scientists and analysts to make sure that the data is accurate, reliable, and available for analysis and decision-making.

Main responsibilities,
1. Des9gning and building data pipelines
2. Storing and managing data
3. Processing ana analyzing data
4. Ensuring data quality and security
5. Monitoring and troubleshooting data systems
6. Collaborating with data scientist and analysts

## Data Engineering pipeline and infrastructure 
- A data pipeline is a series of steps that are used to **"extract, transform, and load"**(ETL) data from various sources to a central location for storage and further analysis. It's designed to move data from one place to another in an automated and efficient manner. 
- Data infrastructure describes the unique combination of data systems, processes, and architecture that allow data to fulfill its function in an organization
- Data pipelines are the connective tissue of this infrastructure.

Data sources that funnel data into data pipeline can be,
- Databases
- SaaS apps
- Data streams
- Data lakes
Destination could be,
- Another database
- Data warehouse
- Operational systems

Typical steps of a data pipeline,
1. Extraction
	from sources like DBs, web APIs, social media, IoT, log files.
2. Transformation 
	Transformed and cleaned to ensure consistency and accuracy.
	Steps may include: data validation, deduplication, normalization
3. Loading
	Load into a central location.
	Ex: Data lake, Data warehouse
4. Processing
	Process to extract insights, features, and create new datasets.
5. Analysis
	Use the data to make predictions, identify patterns and gain insights.


##### Why data pipelines are needed ?
Enterprises need to move data and turn them into actionable information while overcoming challenges like,
- Data corruption
- Conflicts between two sources 
- Redundant information
which can lead to latency.
Data pipelines are designed to solve these issues using a smooth, automated workflow and additionally improve security by restricting access to authorize teams only.

##### Data pipeline tools
All tools have common requirements,
1. Extract data from multiple sources
2. Clean, alter, enrich data to make it ready for analysis
3. Load the data to the single source of information(data lake, data warehouse)

Types of tools,
1. Batch 
	Moving large amounts of data in small batches at regularly scheduled intervals. 
	Ex: Informatica PowerCenter, IBM InfoSphere DataStage
2. Cloud Native
	Optimized for working with cloud based data, like Amazon Web Services (AWS) buckets.
	Organizations save on in-house infrastructure costs. 
	Ex: Blendo, Confluent
3. Open-Source
	Ex: Apache Kafka, Apache Airflow, Talend
4. Real-time
	Designed to handle data in real-time from streaming sources such as telemetry data(IoT), Financial markets. 
	Ex: Confluent, Hevo Data, StreamSets

## Data Visualization
The process of creating graphical representations of data to make it more easily understandable and interpretable.
Ex:
- Chats
- Graphs
- Maps
- other visualization methods

Types of chats,
1. Bar charts: compare the values of different categories
2. Line chart: show changes in data over time
3. Pie chart: show the proportion of different categories
4. Scatter plots: show the relationship between two variables
5. Heat maps: show the distribution of data across a two-dimensional surface
6. Geographic maps: used to show data on a geographical map
7. Bubble chats: show the relationship between three variables
8. Tree maps: show the hierarchical structure of data
9. Word cloud: show the frequency of words in a text

Benefits of data visualization
- Visualization techniques provide a way to see trends, outliers, and patterns in data. 
- Good for non-technical audience. 
- Easy to share information.
- Interactively explore opportunities. 
- Visualize patterns and relationships. 

Disadvantages,
- Its easy to make an inaccurate assumption.
- Biased information/representations. 
- Correlation doesn’t always mean causation. 
- Core messages can get lost in translation.
