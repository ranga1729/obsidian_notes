## Social Networks
Social Network Analysis(SNA) is the field that uses mathematical and statistical tools to analyze the relationships and interactions among individuals, groups, or entities. 

A social network includes, 
	vertices
	points
	ties
	edges
	arcs
	lines
	links
In SNA, each individual is represented as a node or vertex and the connections between them are represented as edges or links. 

SNA can be used to study a wide range social phenomena such as, 
	communication patterns
	influence 
	collaboration 
	social support 
	spread of information

Goal of SNA : Gain insight of a community by examining the relationships that exist between its members, represented as a network.
Analysis involves identifying key individuals, groups, connections between them, which are also known as "components".

## Graphs 
Social Network can be visualized using Graphs.
They show entity-to-entity links and relationships. 

A graph is consist of a pair of sets(V, E).
	V: set of vertices
	E: set of edges connecting pairs of vertices

Adjacency: Two vertices are adjacent if they are connected to each other through an edge
Path: A sequence of edges between two vertices

## Clusters
Cluster analysis helps detecting graph elements with similar properties.
Similarity measures are usually calculated based on topological criteria, node location, or other characteristics of graph elements. 

## Mathematical Foundation
##### 1. Graph Theory
A social network is modeled as a graph $G = (V, E)$ consisting of vertices(or nodes) V representing individuals/entities and a set of edges(or ties) E representing the relationships between them. 

Types of graphs, 
1. Directed graphs: edges have directions
2. Undirected graphs: edges do not have directions
![[Pasted image 20260605012548.png]]
- Geodesic: The geodesic distance is the shortest path between two nodes.
- Density/Degree: The ratio of the number of actual edges to the number of all possible edges in the graph.
##### 2. Centrality Measures
Centrality measures identify the most "important" or influential nodes within a graph based on their structural position. They provide insights of information flow, power distribution, and control within the network.

Measures,
- Degree Centrality: Calculated as the count of edges connected to a node. In directed graphs, this is split into **In-degree** (popularity) and **Out-degree** (gregariousness).
- Betweenness Centrality: Quantifies how often a node acts as a "bridge" along the shortest paths between other nodes.
- Closeness Centrality: Measures how quickly a node can reach all other nodes in the network, calculated as the reciprocal of the sum of the shortest path distances from that node to all others.
- Eigenvector Centrality: Assigns relative scores to nodes based on the principle that connections to high-scoring nodes contribute more to the score than connections to low-scoring nodes (the basis for Google's PageRank).
##### 3. Matrix Algebra
Matrix algebra is the computational engine used to store and manipulate network data.

Measures,
- Adjacency Matrix: An adjacency matrix is a square matrix that represents a graph using boolean values (0's and 1's). Each element in the matrix indicates whether there is a direct path or edge between two vertices in the graph.

## Data Collection
Methods, 
- Surveys
	Pros: Allows data collection on a large number of individuals and relationships
	Cons: Subject to biases such as social desirability and recall bias
- Observation 
	Pros: Provides rich and real-time data on relationship nature
	Cons: Time-consuming and may not be feasible in all settings
- Online data
	Pros: Provides large amounts of diverse relationship data
	Cons: Potential biases like selection bias and privacy concerns

Specialized methods,
- Snowball sampling : Starting with a few individuals and expanding the network through their connections
- Name generators : Asking respondents to list their contacts
- Name interpreters : Having respondents interpret the names of their contacts

Considerations for choosing a data collection method, 
- Goals
- Target population
- Resources
- Strengths and limitations

## Multivariate Analysis
Multivariate analysis (MVA) refers to a set of statistical techniques used to analyze data that involves more than two measurement variables per observation simultaneously. While univariate analysis looks at one variable and bivariate looks at two, multivariate analysis explores the complex relationships and dependencies between multiple independent and dependent variables

Types, 
1. Regression analysis
	Understanding how changes in one variable relate to changes in another variable.
2. Factor analysis
	Identifying underlying factors or dimensions in a network. 
	Purpose is reducing data complexity by grouping similar variables together
3. Cluster analysis
	Grouping nodes in a network based on similarities in multiple variables. 
	Purpose is identifying subgroups or communities within a network.
4. Multidimensional Scaling
	Visualizing relationships between variables in a network. 
	Purpose is identifying patterns or clusters of variables
5. Variable selection
	Choosing relevant variables aligned with research question
6. Statical Methods
	Employing appropriate statistical techniques to test significance and control for confounding variables

## Visualization
Types,
1. Node-Link Diagram
	Common network visualization depicting nodes as circles/dots and relationships as lines/edges. Purpose is revealing overall network structure and highlighting centrality of individual.
2. Matrix Diagram
	Visual representation of node relationships in a matrix format. Purpose is uncovering patterns and clusters within the network.
3. Heat map
	Matrix diagrams using color to represent the strength of relationships between nodes. Purpose is visualizing relationship strength in an intuitive and visually appealing manner.
4. Force-Directed Layouts
	Visualization technique positioning nodes based on their relationships using algorithms. Purpose is unveiling clusters, subgroups, and overall network structure.

Considerations for Effective Network Visualization
- Selecting the appropriate method
- Clear labeling and colors, legends to ensure easiness to understanding
- Incorporating interactive features to allow users to explore and manipulate the visualization.
