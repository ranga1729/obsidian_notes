Most Android-powered devices have built-in sensors that measure motion, orientation, and various environmental conditions. 
These sensors are capable of providing raw data with high precision and accuracy, and are useful if you want to 
- monitor three-dimensional device movement or positioning, 
- you want to monitor changes in the ambient environment near a device.

Categories of sensors,
1. Motion sensors
	Measure acceleration forces and rotational forces along three axes
	Ex: Accelerometer, Gravity sensor, Gyroscope, Rotational vector sensor
2. Environmental Sensors
	Measure various environmental parameters, such as ambient air temperature and pressure, illumination, and humidity.
	Ex: Barometer, Photometers, Thermometers
3. Position Sensors
	Measure the physical position of a device. 
	Ex: Orientation sensor, Magnetometer, Proximity Sensors

Sensor availability can be varies based on the,
- Device
- Android version

#### Sensor Manager
The `SensorManager` is a system service class that acts as the gateway to the device's physical hardware sensors.
It's responsibilities, 
- Discover available sensors
- Register an unregister sensor event listener 
- Read raw sensor data
- Provide constants for accuracy, data acquisition rates and calibration

Framework classes used to be used, 
- `Sensor`: Determine specific sensor's capabilities 
- `SensorEvent`: Info about event, including raw sensor data
- `SensorEventListener`: Receives notification about sensor events

#### Compute the Device Orientation
![[Pasted image 20260603212017.png]]
By computing a device's orientation, you can monitor the position of the device relative to the earth's frame of reference (specifically, the magnetic north pole).

The system computes the orientation angles by using a device's geomagnetic field sensor in combination with the device's accelerometer. Using these two hardware sensors. 

- Azimuth(Degree of rotation about the z-axis)
	Angle between the device's current compass direction and magnetic north. 
	If the top edge of the device faces magnetic north, the azimuth is 0 degrees; 
	if the top edge faces south, the azimuth is 180 degrees. 
	Similarly, if the top edge faces east, the azimuth is 90 degrees, and if the top edge faces west, the azimuth is 270 degrees
- Pitch((degrees of rotation about the x-axis)
	The angle between a plane parallel to the device's screen and a plane parallel to the ground. 
	If you hold the device parallel to the ground with the bottom edge closest to you and tilt the top edge of the device toward the ground, the pitch angle becomes positive. 
	Tilting in the opposite direction moving the top edge of the device away from the ground causes the pitch angle to become negative. 
	The range of values is -180 degrees to 180 degrees.
- Roll(degrees of rotation about the y-axis)
	This is the angle between a plane perpendicular to the device's screen and a plane perpendicular to the ground. 
	If you hold the device parallel to the ground with the bottom edge closest to you and tilt the left edge of the device toward the ground, the roll angle becomes positive. 
	Tilting in the opposite direction moving the right edge of the device toward the ground causes the roll angle to become negative. The range of values is -90 degrees to 90 degrees.
