## 1.2 The Mobile Ecosystem
Layers of the mobile ecosystem,
	![[Pasted image 20260216070112.png]]
#### 1. Operators
Operators role is to create and maintain a specific set of wireless services over a reliable cellular network. 
Types,
	Mobile Network Operators(MNOs),
	Mobile service providers,
	Wireless carriers,
	Cellular companies.
Involved activities,
- Install cellular networks
- Operator cellular networks
- Make services(ex: internet) available for subscribers.
- Handling billing and support
#### 2. Networks
Operators operates wireless networks and the type of radio and antenna determines the capability of the network and the services you can enable on it. 

**Generations of Communication Technology**
Although the core technology empower voice communication has stayed relatively the same. But data speed the network can deliver has been improved over the time. 

Ex: 2G, 3G, 4G, etc...

**First Generation(1G)**
- Entirely analog. 
- Circuit-switched networks were used for voice calls.
- Only voice calls were available. 
- Japan's NTT(NTT Nippon Telegraph and Telephone) first launched the first generation automatic cellular network in 1989. 
- Key issues,
	Low voice call quality.
	Phone sizes were much larger.
	Security issues in networks. 
	Frequent call droppings. 
	Capacity of the network was limited.

**Second Generation(2G)**
- Structure was similar to first gen networks. 
- Transformed to digital networks. 
- Caller identity(caller's name and phone number) and text SMS services were introduced. 
- Standards used,
	GSM : Global System for Mobile Communication
	GPRS : General Packet Radio Service
	EDGE : Enhanced Data rates for GSM Evolution
	HSCSD : High-Speed Circuit-Switched Data
- Key features,
	Text SMS and MMS (Multimedia Message Service)
	Fax and email services
	Internet was introduced to mobile devices.
	Higher data rates
- Key issues,
	Weak signals
	Low internet speed

**Third Generation(3G)**
- Standards used,
	W-CDMA : Wideband Code Division Multiple Access
	UMTS : Universal Mobile Telecommunication System
	UMTSTDD : UMTS + Time Division Duplexing
	TD-CDMA : Time Division Code Division Multiple Access
	HSAP : High-Speed Packet Access
	HSDPA : High-Speed Downlink Packet Access
	HSUPA : High-Speed Uplink Packet Access
- Key features,
	- Support global roaming
	- Support larger email
	- Easy to browse websites
	- GPS became common
	- Video calls and video conferencing became possible
	- Support high-resolution TV
	- Support online multiplayer games
- Issues,
	- Building 3G networks were expensive.
	- Expensive for users to use 3G networks

**Fourth Generation(4G)**
- Existing GSM/EDGE(2G)/ and UMTS/HSPA(3G) networks were improved. 
- New user experience,
	- Less buffering
	- High voice quality
	- Easy access to instant messaging services
	- Social media
	- Quality streaming
	- Faster download speeds

## 1.3 Mobile Strategy
**Rule #1** : 
	Forget everything you think you know about mobile technologies and start think from business perspective, and users, your development capacity. 
**Rule #2** : 
	Do no depend on outdated documentation. 
	Understand what really happens in the real work environment. 
**Rule #3** :
	Do not let constraints to ruin good project ideas at early stages.
**Rule #4** :
	Understand user's goals and their context.
	Figure out the tasks the users want to perform. 
**Rule #5** : 
	Start with the devices that best represent your core customer.
	Do a market research to find out the recommended devices for your target customer. 
**Rule #6** : 
	Do not apply the same rationale to mobile devices as in the web technologies. 
	Create a tailored user experience. 
**Rule #7** : 
	Keep it simple. 
	Limit the features to most crucial to users 
	Determine the need that will motivate users to interact with the application.
