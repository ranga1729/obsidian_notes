#### What is Android ?
- An mobile OS based on Linux Kernel. 
- Powers devices like watches, TVs, Cars, ...
- Open Source.

#### Android System Architecture
![[Pasted image 20260520091731.png]]

1. System app & Use apps : 
	System apps have no special status. They provide key capabilities to developers. 
	Ex: Devs can write an app to deliver a SMS via a system app.
2. Java API Framework
	The entire feature set of Android OS is available through Java APIs. 
	Ex: activity manager, notification manager
3. Native C/C++ Libraries & Android Runtime
	Core C libraries provide access to native android system components and services. 
	Each app runs in its own process with its own instance of the android runtime.
4. Hardware Abstraction Layer(HAL)
	Standard interface that expose device hardware capabilities as libraries. 
	Ex: Camera, Bluetooth, ...
5. Linux Kernel
	Threading and low-level memory management. 
	Includes Security features and Drivers. 

#### What is an Android App ?
- Written with Java and XML using the Android Software Development Kit(SDK). 
- Uses Android libraries and Android Application Framework.
- Executed by Android Runtime Virtual Machine(ART)

#### What is Android Studio ?
The official IDE for android development. It offers features to enhance the the productivity of development. 
Ex: 
- A flexible Gradle-based build system
- A fast emulator
- A unified env for for all devices
- Apply changes to push code/resource changes without restarting your app. 
- Code templates & GitHub integration to help build common features. 
- Testing tools/frameworks
- Lint tools to catch performance, usability, version compatibility
- C++ and NDK(Native Development Kit) support.

#### Gradle Build System
Gradle an advanced, opensource build system utilized as the official build tool for Android application development.
While android studio facilitate write code, it doesn't compile or package the code. Instead Android Studio delegates these compilations, optimizations and packaging to Gradle.

![[Pasted image 20260520115328.png]]
Gradle acts as the coordinator between compilers, source code files, config files and external dependencies to generate the final deployable asset(an APK)/

Steps,
1. **Compilation:** Compile your code(`.kt` or `.java`) and converts the resulting `.class`bytecode into Dalvik Executable(`.dex`) files via the D8/R8 compiler. 
2. **Resource Processing:** Compile app resources(XML layouts, drawables, assets) into a structured binary format. 
3. **Dependency Resolution:** Fetches required remote and local software libraries(JAR or AAR files) declared in the build config files. 
4. **Packaging:** Combine the DEX files, compiles resources, and manifests, then signs the package using the specified debug or release keystroke cryptographic keys via the APK packager to produce the final executable application.
