## 1. Requirement Analysis/Design
Start when SRS document is ready. 
Testing team identifies, 
- Scope : Area of the product needed to be focused. 
- Verification and validation key points : Gathering testing priorities. 
- Time : Time needed for testing

Other factors needs to be identified, 
- Functional and logical relationships between modules
- Functional and non-functional requirements 

Activities needs to be performed, 
- Scope definition 
- requirement Traceability Matrix(RTM) preparation
- Automation analysis

#### Scope Definition 
Identify the scope needs to be tested.
Identify the needed type of tests. 
Identifies the prerequisites and testing environments.
#### Requirement  Traceability Matrix(RTM) preparation
RTM is a document maps requirements with test cases.

##### Entry Criteria
Conditions required to begin a particular test phase of SLTC. 
Common entry criteria to mark the beginning of the testing ,
- Approved requirements
- Complete or partially testable code
- Availability of test data
- Availability of test cases
- Complete Test environment

Common entry criteria for unit testing, 
- Planning phase is completed
- Properly reviewed system design, technical design and other docs
- Business and functional requirements
- Availability of testable code
- Availability of test env
