### Network Security Issue Remediation and Infrastructure Hardening
- Asset : Any data, device, or other component of the environment that supports information related activities. 
- Vulnerability : Weakness inside the asset that could be used to gain unauthorized access.
- Threat : A possible danger to the computer system. A successful exploitation of vulnerability is a threat.
- Exploit : Something that takes advantage of vulnerability in an asset. 
- Infrastructure : Network devices, Network services, and Servers (web, email, application servers, etc.).

**Vulnerability Assessment(VA) ?**
The process of scanning an information system to find out the weaknesses and document them accordingly. 

Motivation of conducting an Vulnerability assessments,
- Legal and regulatory constraints
- risk to the business(reputation, financial)
- Service interruption caused by exploitations

Testing approaches,
- Blackbox testing
- White box testing
- Gray box testing

Vulnerability Assessment techniques,
- Static analysis
	Analyze the code structure, design and contents of the system.
	Slow.
	Tools: Veracode, Semmle
- Manual testing
	Tester use his knowledge and experience to find out the vulnerabilities in the system.
	Low budget.
	Slow.
	Tools: no professional tools used
- Automated testing
	Use automated tools specifically build for the particular application. 
	Very quick.
	Minimum false positive.
	Expensive
	Tools: Nessus, Rapid7, Acunetix, CoreImpact, Open source tools
	Cloud tools : Qualys
	Penetration testing is also available to certain extent
- Fuzz testing
	Test the robustness of the system by imputing invalid or random data. 

Workflow of Vulnerability Assessments,
![[Pasted image 20260609135202.png]]

1. Scoping the assessments.
	Criteria: Time, resources and budget, number of services/hosts, information exposure(black, white, gray testing)
2. Reconnaissance
	Gain much information as possible in a very less intrusive way. 
	Techniques,
	- Social engineering
	- Internet searching and google hacking
	- Passive network scanning and sniffing
	- Dumpster diving
3. Scanning
	Nmap - open ports, open services, network device discovery, etc.
	ZAP - web application vulnerability assessment
	Metasploit - vulnerability assessment and penetration testing
4. Vulnerability scoring and reporting
5. Vulnerability assessment and penetration testing
	Security patches/updates
	System hardening
	Configuring using security best practices of the industry. 
6. Hardening the system
	The process of making the system robust for intruder attacks as much as possible 
	Could be both infrastructure (firewall, network) and deployment platform (web application server. 
	Measures,
	- Strengthening permissions and access control 
	- Using secure cryptographic algorithms 
	- Removing unnecessary data/apps from the system 
	- Removing unwanted modules/components 
	- Stop unused services 
	- Removing unused libraries 
	- Removing software building/compiling utilities 
	- Enabling firewall
