## Mobile Devices

1. Lack of physical security control
2. Use of untrusted mobile devices
3. Use of untrusted networks
4. Use of applications created by unknown parties
5. Use of untrusted content 
6. Use of location service

Security strategy,
1. Device security
	Enable auto-lock
	Enable password/PIN protection
	Avoid using autocomplete features to remember username/passwords
	Enable remote wipe
	Keep the OS and software up to date
	Prohibit sensitive data to store on the phone/use encryption
2. Traffic security
	Encryption and authentication
3. Barrier security
	Protect network from unauthorized access

## IEEE 802.11 Wireless LAN Overview
![[Pasted image 20260608163026.png]]
This is a physical layer protocol.
It defines frequency bands and antenna characteristics. 
Media Access Control(MAC) layer receives data from a higher-layer protocol. 

On transmission MAC, assemble data into a frame, with address and error-detection fields.
On reception, disassemble frame, and perform address recognition and error detection.

Services provided by IEEE 802.11,
- Association
- Disassociation
- Re-association
- Authentication
- De-Authentication
- Distribution
- Integration
- MSDU delivery
- Privacy

Security Protocols available in IEEE 802,
- Wired Equivalent Privacy(WEP)
- Wi-Fi Protected Access(WPA)
- Robust Security Network(RSN)

802.11i RSN security specification defines these services,
- Authentication
- Access Control
- Privacy with message integrity

IEEE 802.11i Phases of Operation, 
1. Discovery : Access points use messages called Beacons and Probe Response to advertise it IEEE 8-2.11i security policy. 
2. Authentication: Wireless stations and authentication server prove their identities to each other.
3. Key generation and distribution: Wireless stations and access points negotiate cryptographic keys.
4. Protected data transfer: Exchange data frames through the access point securely.
5. Connection termination: Secure connection is torn down and restore to the original state.
